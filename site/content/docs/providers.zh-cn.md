Lumi 自身不提供云端模型额度。第一次启动时，需要选择一个模型服务商，并填写你在该服务商申请的凭据。Lumi 使用一个“当前服务商”作为默认来源，也可以在模型设置中选择其他已就绪的服务商。

## 选择服务商

### 阿里云百炼

需要准备：

- API Key
- 业务空间 ID
- 业务空间所在地区

Lumi 会使用内置的文本和图片模型配置。填写信息后选择“连接并开始使用”或“保存并验证”。只有连接检查通过，服务商才适合用于创建项目。

### Cloudflare AI Gateway

需要准备：

- Cloudflare Account ID
- Cloudflare API Token

接口地址由 Lumi 根据 Account ID 固定生成，使用 Responses API。默认文本模型和图片模型均为 `openai/gpt-5.6-terra`，可分别在下拉框中选择 Terra 或 `openai/gpt-5.6-sol`。API Token 需要 Account → Workers AI → Read 权限。升级后若提示需要验证，重新保存并验证即可。

## 保存并验证连接

1. 在首次启动页选择一个服务商。
2. 填入界面要求的 ID、区域和密钥。
3. 选择“连接并开始使用”。已经进入 Lumi 后，可从“设置 → 模型服务商”重新打开配置。
4. 等待连接状态变为“连接已验证”。如果失败，保留页面上的错误信息并逐项核对凭据、空间/账户和网络。

{{< callout type="note" title="密钥如何保存" >}}
API Key 或 Token 会在本机加密保存，界面不会再次显示完整值。留空保存会保留已有密钥；“重置密钥”会删除本机已保存的凭据。
{{< /callout >}}

## 切换当前服务商

可以同时保存多个服务商配置，但始终只有一个当前服务商。打开“设置 → 模型服务商”，在已验证的配置上选择“设为当前模型服务商”。没有全局或项目模型覆盖的新任务会使用新的当前配置；已经入队的任务保留创建时冻结的模型设置。

## 配置项目默认模型

在“设置 → 模型服务商”的“项目默认模型”区域，可以分别配置文本默认、图片默认、聊天文本、故事与漫画脚本、参考设定选择。每项修改立即保存，也可以选择“恢复继承”。支持的图片模型还提供思考模式和提示词智能改写开关。

新旧项目会持续继承全局默认，项目自己的配置优先。文本场景依次使用：项目场景覆盖 → 项目文本默认覆盖 → 全局场景默认 → 全局文本默认 → 当前服务商默认。图片依次使用项目图片覆盖、全局图片默认、当前服务商默认；任务中显式指定的模型优先于这些设置。

例如，全局故事模型设为 A，某项目文本默认设为 B，该项目的故事生成使用 B。清除项目覆盖后，会使用最新的全局配置。修改全局默认不会改变已经创建的任务。

页面会展示继承值和当前有效模型。保存的模型失效时会保留配置并提示，后续任务回退到可用的继承模型；没有可用模型时，需要先修复服务商连接或模型设置。

## 常见连接问题

- **提示缺少凭据**：确认没有把 Account ID、业务空间 ID 和密钥填错字段。
- **连接检查失败**：核对凭据是否仍有效、所在地区是否正确，以及当前网络能否访问服务商。
- **密钥不可用**：操作系统安全存储中的根密钥可能缺失或发生变化，需要重新填写并保存凭据。
- **调用产生费用**：费用由模型服务商根据你的账户和模型使用情况结算；Lumi 只展示本机采集的调用与用量信息。

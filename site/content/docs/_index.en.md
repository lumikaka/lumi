The Lumi guides follow one complete path: make the app and model provider work, create a first picture book, then understand project storage and troubleshooting. If this is your first time, follow the pages in order.

{{< callout type="note" title="Before you begin" >}}
Current desktop builds support Apple Silicon Macs and Windows x64. AI writing and image generation require your own Alibaba Cloud Model Studio or Cloudflare AI Gateway credentials, and that provider may charge for usage.
{{< /callout >}}

## Recommended path

1. Install Lumi and pass the first-launch system prompts.
2. Connect a provider and confirm that Lumi reports a verified connection.
3. Use YOLO quick creation to make an editable first draft.
4. Learn the story, premise, storyboard, image-candidate, and export workspaces.
5. Finish with local projects and troubleshooting, then establish your own backup routine.

## How Lumi works

Every picture book is a self-contained local project. AI can produce a first pass, but prose, premise items, storyboards, and image candidates stay editable. A new generation never requires you to abandon the previous version.

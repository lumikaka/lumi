# Guide：导出漫画

用于导出整个项目或单个章节的 ZIP、PDF。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic-export.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 检查目标范围的 export readiness，并读取 `missing_sections` 的 `page_role` 和 `body_page_no`；有缺图时准确说明缺封面、第 N 个正文页还是封底，再让用户决定补图或允许缺图导出。
3. 创建导出任务，并按需读取 Production Task 状态和事件。
4. 任务完成后按范围、格式或 task UUID 读取导出结果，只有已完成记录才作为交付结果。

空内容、缺图未获允许、排队或失败都不能报告为导出完成。API 细节以所读 Contract 为准。

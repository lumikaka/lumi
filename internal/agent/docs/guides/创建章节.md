# Guide：创建章节

用于手动创建章节、批量规划章节，或为已有空章节生成正文。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/chapter.md`；涉及 AI 生成时再读 `/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 需要了解项目故事背景或整体情节时，先读 `/api/v1/agent-docs/api/story.md`，再用 `GET /api/v1/projects/{project_uuid}/story-profile` 读取总纲；`response_filter` 使用 `.data | {uuid,revision,story_md,projection_state}`，其中 `story_md` 是完整总纲正文。路径和返回字段必须以该 Contract 为准。
3. 用 `request_api` 读取章节列表，确定不冲突的章节编号和目标章节。
4. 单章直接创建；批量规划调用章节批量生成；为已有章节生成正文则调用章节生成。
5. 异步任务按需读取 Task 状态和事件；完成后重读章节列表或目标章节。

本地文件的 multipart 导入不能由当前工具安全完成时，引导用户使用界面导入或粘贴正文，不得虚构上传。API 细节以所读 Contract 为准。

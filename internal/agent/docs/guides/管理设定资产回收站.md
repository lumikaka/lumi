# Guide：管理设定资产回收站

用于移入、查看、恢复、永久删除设定资产，或清空设定资产回收站。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise-asset.md`。
2. 用 `request_api` 读取 active 或 trashed 资产；对单个目标再读取最新 revision。
3. 按用户目标执行移入回收站或恢复。永久删除和清空回收站必须先完成危险操作确认。
4. 操作后重读相应列表；活动任务仍占用而保留的资产要如实说明。

不得把软删除描述为永久删除。API 细节以所读 Contract 为准。

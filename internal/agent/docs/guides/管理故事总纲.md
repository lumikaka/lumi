# Guide：管理故事总纲

能力 ID：`story_profile_manage`

用于编辑、生成、从章节重建、导入或查看故事总纲版本。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/story.md`；涉及生成任务时再读 `/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取当前 Story Profile、最新 revision；需要比较时再读取版本列表。
3. 按用户目标更新完整总纲，或创建生成、重建、导入、重新投影任务。危险操作先完成确认。
4. 异步任务按需读取 Task 状态和事件；完成后重读 Story Profile，只有事实状态成功才报告完成。

冲突时重新读取最新内容再合并；不要用旧 revision 覆盖。API 的 method、path、字段和响应以所读 Contract 为准。

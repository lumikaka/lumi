# Guide：生成漫画分镜

用于为一个章节生成完整漫画分镜。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/chapter.md`、`/api/v1/agent-docs/api/comic.md`、`/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取目标 Chapter、Comic 状态和现有 Sections，确认生成范围。
3. 调用漫画分镜生成入口并完成危险操作确认；该调用会创建可跟踪的 Story Task，并由后端触发对应 Workflow。
4. 按需读取 Task 状态和事件；完成后重读 Comic 状态和 Sections。等待确认、失败或取消都不能报告为完成。

已有 Sections 时不得未经确认直接覆盖。API 细节以所读 Contract 为准。

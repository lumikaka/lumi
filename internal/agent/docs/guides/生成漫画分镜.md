# Guide：生成漫画分镜

用于为一个章节生成完整漫画分镜。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/chapter.md`、`/api/v1/agent-docs/api/comic.md`、`/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取目标 Chapter、Comic 状态和现有 Sections 的 `page_role`，确认生成范围。该生成只规划正文页，不覆盖封面或封底。
3. 以完整参数调用一次漫画分镜生成入口；若返回 `agent_tool_confirmation_required`，运行时会生成确认卡片并暂停。不要调用 `request_user_input` 或重放生成请求；用户确认后运行时自动执行原请求，创建可跟踪的 Story Task 并由后端触发对应 Workflow。
4. 按需读取 Task 状态和事件；完成后重读 Comic 状态和 Sections。等待确认、失败或取消都不能报告为完成。

已有正文页时不得未经确认直接覆盖；封面或封底存在不代表正文页已有可用分镜，仍应检查 active `body` 的 Storyboard。API 细节以所读 Contract 为准。

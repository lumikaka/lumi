# Guide：管理漫画页面与画面段落

用于创建、修改、排序或删除封面、正文页、封底或条漫画面段落。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic.md` 和 `/api/v1/agent-docs/api/comic-section.md`。
2. 用 `request_api` 读取 Chapter 的 Section 列表和 `page_role`；修改或删除时再读取目标 Section 和最新 revision，并冻结目标 Section 的 `page_role` 作为本次操作前提。
3. 先读取项目 `picture_book.format`：普通绘本把 `front_cover` / `body` / `back_cover` 称为封面 / 正文页 / 封底；`vertical_strip` 只能创建 `body`，称为画面段落。
4. 创建时先检查页面序列：普通绘本为空时先创建 `body`，已有 active `body` 后才能创建封面或封底；条漫始终只创建 `body`。再按用户目标更新、重排或删除。重排和删除必须按 Overview 的危险操作确认协议执行：提交一次完整 `request_api` 后由运行时生成确认卡片并暂停；不要调用 `request_user_input` 或自行重放，用户确认后由运行时自动执行原请求。
5. 操作后重读 Section 列表和必要的目标详情，核对 `page_role`、绝对装订顺序和最终状态。

Agent 重排必须仅提交全部 active 正文页的完整顺序，不得遗漏正文页，也不得携带封面或封底 UUID。普通绘本删除正文页或把它改成特殊页时，不得移除最后一个 active `body`；条漫可删除最后一个画面段落回到 `empty`。API 细节以所读 Contract 为准。

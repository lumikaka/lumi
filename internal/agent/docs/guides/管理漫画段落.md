# Guide：管理漫画段落

用于创建、修改、排序或删除漫画段落。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic.md` 和 `/api/v1/agent-docs/api/comic-section.md`。
2. 用 `request_api` 读取章节的 Section 列表；修改或删除时再读取目标 Section 和最新 revision。
3. 按用户目标创建、更新、重排或删除。重排和删除必须先完成危险操作确认。
4. 操作后重读 Section 列表和必要的目标详情，确认最终顺序或状态。

重排必须提交完整顺序，不得遗漏现有 Section。API 细节以所读 Contract 为准。

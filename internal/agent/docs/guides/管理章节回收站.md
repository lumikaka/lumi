# Guide：管理章节回收站

用于移入、查看、恢复、永久删除章节，或清空章节回收站。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/chapter.md`。
2. 用 `request_api` 读取 active 或 trashed 章节；对单个目标再读取最新 revision。
3. 按用户目标执行移入回收站或恢复。永久删除和清空回收站必须按 Overview 的危险操作确认协议执行：提交一次完整 `request_api` 后由运行时生成确认卡片并暂停；不要调用 `request_user_input` 或自行重放，用户确认后由运行时自动执行原请求。
4. 操作后重读相应列表；只报告实际删除或恢复的项目，保留项和冲突如实说明。

不得把软删除描述为永久删除。API 细节以所读 Contract 为准。

# Guide：创建设定资产

能力 ID：`premise_asset_create`

用于从新生成图片或 ready upload 创建设定资产。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise-asset.md`；需要画风时再读 `/api/v1/agent-docs/api/premise.md`。
2. 用 `request_api` 读取必要的画风和现有资产，避免重复。
3. 需要生图时调用 `image_gen`；已有项目图只能作为当前 Turn Reference，不能直接充当新资产文件。已有 ready upload 则直接使用。
4. 用 `request_api` 创建设定资产，并以成功响应中的资源为完成依据。

图片来源必须符合 Contract，不能同时提交两种来源，也不能复用已消费 UUID。API 细节以所读 Contract 为准。

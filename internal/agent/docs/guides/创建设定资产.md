# Guide：创建设定资产

用于从新生成图片或 ready upload 创建单个设定资产。

用户一次要求创建多个设定项，或输入包含多个编号条目时，立即停止本 Guide。禁止调用 `image_gen`，禁止循环调用设定资产 API；只读取 `/api/v1/agent-docs/guides/生成项目设定.md`，执行设定总览图生成与确认拆解流程。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise-asset.md`。`image_gen` 默认自动应用项目 `default_style`，不得只为获取画风而读取 `/api/v1/agent-docs/api/premise.md`，也不得在 Prompt 中重复画风。
2. 用 `request_api` 读取必要的项目事实和现有资产，避免重复。
3. 需要生图时调用 `image_gen`；只有用户明确要求另一种画风时才设置 `use_default_style=false`。已有项目图只能作为当前 Turn Reference，不能直接充当新资产文件。已有 ready upload 则直接使用。
4. 用 `request_api` 创建设定资产，并以成功响应中的资源为完成依据。

图片来源必须符合 Contract，不能同时提交两种来源，也不能复用已消费 UUID。API 细节以所读 Contract 为准。

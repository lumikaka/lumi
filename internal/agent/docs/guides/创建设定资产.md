# Guide：创建设定资产

用于从新生成图片或 ready upload 创建单个设定资产。

用户要求多个设定项或输入多个编号条目时，立即停止本 Guide。禁止调用 `image_gen`，禁止循环调用设定资产 API；只读取 `/api/v1/agent-docs/guides/生成项目设定.md`，生成总览图并确认拆解。

## 生图提示词规则

生图时必须将默认要求写入 `image_gen.prompt`：每个设定项必须是一个独立视觉主体：单个角色、单个完整道具、单个标志，或一个边界清楚的地点缩景。画布背景均匀纯白 #FFFFFF。单一视角，主体完整、居中并留边距；不添加多视图、细节分解、标题、标签、说明文字或装饰版式。

用户明确要求只覆盖冲突的默认规则：三视图仍默认白底、无说明文字；森林背景仍默认单一主体、单一视角。“设定图”“角色设计参考图”等泛称不视为特殊要求。ready upload 不为此重绘。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise-asset.md`。`image_gen` 的 `generate` 默认自动应用项目 `default_style`，不得只为获取画风而读取 `/api/v1/agent-docs/api/premise.md`，也不得在 Prompt 中重复画风。
2. 用 `request_api` 读取必要的项目事实和现有资产，避免重复。
3. 需要生图时调用 `image_gen`；只有用户明确要求另一种画风时才设置 `use_default_style=false`。已有项目图只能作为当前 Thread 中出现过的冻结 Reference，不能直接充当新资产文件；当前 Turn 的同一资源优先，否则使用最近的历史冻结快照。已有 ready upload 则直接使用。`image_gen` 成功只表示文件已生成；没有用户反馈或可验证的工具错误时，不得凭猜测自行重复生成。
4. 用 `request_api` 创建设定资产，并以成功响应中的资源为完成依据。

图片来源遵循 Contract，不得同时提交两种来源或复用已消费 UUID。

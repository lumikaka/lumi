# Guide：恢复漫画快照

用于查看并恢复章节的漫画快照。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic-snapshot.md` 和 `/api/v1/agent-docs/api/comic.md`。
2. 用 `request_api` 读取快照列表，再读取目标快照详情和当前 Section 列表。
3. 向用户说明将被覆盖的范围，完成危险操作确认后恢复目标快照。
4. 恢复后重读 Section 列表和 Comic 状态，按实际结果报告。

未读取快照详情前不得恢复，也不得把历史缺失图片描述为已恢复。API 细节以所读 Contract 为准。

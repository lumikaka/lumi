# Guide：恢复漫画快照

用于查看并恢复章节的漫画快照。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic-snapshot.md` 和 `/api/v1/agent-docs/api/comic.md`。
2. 用 `request_api` 读取快照列表，再读取目标快照详情中每个 Section 的 `page_role`，并读取当前 Section 列表。普通绘本的目标快照必须至少包含一个 active `body`，不能恢复 empty 或只有封面/封底的快照；条漫可恢复 empty，但不能包含特殊页。
3. 向用户说明将被覆盖的范围和上述角色校验，以完整参数调用一次恢复入口；若返回 `agent_tool_confirmation_required`，运行时会生成确认卡片并暂停。不要调用 `request_user_input` 或重放恢复请求；用户确认后由运行时自动恢复目标快照。
4. 恢复后重读 Section 列表和 Comic 状态，按实际结果报告。

未读取快照详情前不得恢复，也不得把历史缺失图片描述为已恢复。API 细节以所读 Contract 为准。

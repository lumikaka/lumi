# Guide：生成、导入与选择漫画图片

用于生成、导入或选择漫画图片版本。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic-section.md` 和 `/api/v1/agent-docs/api/comic.md`；生成时再读 `/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取目标 Section、当前 Storyboard、图片版本和最新 revision。
3. 按用户目标创建图片生成任务、用 ready upload 导入图片，或选择已有 variant。
4. 生成任务按需读取 Production Task 状态和事件；完成或选择后重读 Section 和图片版本。

没有 Storyboard 时不要盲目生成。本地文件未成为 ready upload 时引导用户使用界面导入。API 细节以所读 Contract 为准。

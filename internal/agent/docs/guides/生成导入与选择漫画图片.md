# Guide：生成、导入与选择漫画图片

用于生成、导入或选择页面图片版本。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic-section.md` 和 `/api/v1/agent-docs/api/comic.md`；生成时再读 `/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 批量生成时，用 `request_api` 只允许调用一次 Section 列表接口，读取 `uuid`、`section_no`、`page_role`、`has_storyboard`、`revision`；按装订顺序映射 UUIDv7。`section_no` 不是正文页码，不逐个读取 Section。
3. 多 Section 生成必须只调用一次 `POST /api/v1/projects/{project_uuid}/chapters/{chapter_uuid}/comic-image-generation-batches`。禁止循环调用单图接口，也禁止使用通用 `image_gen` 代替漫画图片任务。
4. 单页生成先读目标 Section；导入或选择 variant 时再读图片版本和最新 revision。
5. 图片任务冻结目标的 `page_role`。运行期间不改角色；角色漂移会拒绝提交结果，此时重读 Section 后按当前角色生成。
6. 单图和批量均以内联 Workflow 等待终态，期间不查进度、不提前回复“已提交”。恢复同一 Run 后读终态 Tool Result 并回复一次；成功时按需重读 Section 和图片版本，失败或取消不自动重试。

批量接口自动冻结分镜、画风、设定引用和模型，不接受逐页参数。`has_storyboard=false` 或“Section 尚无 Storyboard”时，不调用 `request_user_input`，不盲目出图：返回缺失 Section UUID 及补脚本步骤，按《编辑与选择漫画分镜》（`/api/v1/agent-docs/guides/编辑与选择漫画分镜.md`）写回完整脚本后重试。整章补分镜走《生成漫画分镜》，遵守覆盖确认，终态后重读列表映射新 UUID；不得默认覆盖已有脚本。文件未 ready upload 时从界面导入。

接口返回 `queued` 只表示图片任务已创建，不能报告为图片已经生成完成。API 细节以所读 Contract 为准。

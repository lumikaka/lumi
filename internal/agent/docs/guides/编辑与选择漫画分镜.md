# Guide：编辑与选择漫画分镜

用于编辑完整分镜文本，或选择已有分镜版本。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/comic-section.md` 和 `/api/v1/agent-docs/api/storyboard.md`。
2. 用 `request_api` 读取目标 Section、完整当前 Storyboard、版本列表和最新 revision。
3. 编辑时提交完整替换后的 Markdown；恢复历史时选择目标 variant，并使用最新 revision。
4. 写入后重读 Section；冲突时重新读取完整内容再合并。

不得提交局部补丁或用旧 revision 覆盖。API 细节以所读 Contract 为准。

# Guide：生成项目设定

用于维护整体画风，并生成、导入、选择、忽略或拆解项目设定图。用户批量创建设定项或输入多个编号条目时，必须使用本 Guide，将完整输入作为一个批次处理；禁止逐项调用 `image_gen` 或设定资产创建 API。

## API 调用顺序和说明

1. 请求 API 前，先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise.md`、`/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取当前 Premise 和来源；批量生成时只创建一个 Premise Source，保存完整输入和画风。
3. 对该 Source 只创建一次 Premise 设定图任务；不得调用 `image_gen`。聊天调用会创建当前 Thread 内的两阶段 Workflow，并持久化等待。
4. 后台在总览图生成成功后直接拆分本次生成图，无需确认、选择候选图或再次调用拆解接口。工具等待整个 Workflow 终态后返回；不要轮询任务，不要承诺未注册的“稍后检查”。
5. 拆解完成后，从工具结果获取 `setting_image_uuid` 和 `premise_asset_uuids`；先读 `/api/v1/agent-docs/api/premise-asset.md`，再用 `request_api` 读取本批资产并汇报。失败时按 Workflow 当前步骤说明原因，不重复创建批次。

普通界面和外部 MCP 的设定图生成仍只创建总览图任务，需要另行选择或拆分。对已有设定图的独立拆解仍可调用拆解接口。

本地文件尚未成为 ready upload 时，引导用户在界面上传，不得虚构 UUID。API 细节以所读 Contract 为准。

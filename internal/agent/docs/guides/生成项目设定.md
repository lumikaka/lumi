# Guide：生成项目设定

能力 ID：`premise_generate`

用于维护整体画风，并生成、导入、选择、忽略或拆解项目设定图。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise.md`；涉及生成任务时再读 `/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取当前 Premise、来源和设定图；修改画风时使用最新 revision。
3. 创建或选择来源后，按目标生成设定图、导入 ready upload、选择当前设定图、忽略来源或创建拆解任务。
4. 异步任务按需读取 Production Task 状态和事件；完成后重读 Premise、来源及设定图。

本地文件尚未成为 ready upload 时，引导用户在界面上传，不得虚构 UUID。API 细节以所读 Contract 为准。

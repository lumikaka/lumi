# Guide：生成项目设定

用于维护整体画风，并生成、导入、选择、忽略或拆解项目设定图。用户批量创建设定项或输入多个编号条目时，必须使用本 Guide，将完整输入作为一个批次处理；禁止逐项调用 `image_gen` 或设定资产创建 API。

## API 调用顺序和说明

1. 请求 API 前，先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise.md`、`/api/v1/agent-docs/api/generation.md` 和 `/api/v1/agent-docs/api/task.md`。
2. 用 `request_api` 读取当前 Premise 和来源；批量生成时只创建一个 Premise Source，保存完整输入和画风。
3. 对该 Source 只创建一次 Premise 设定图任务，并按 Contract 读取 Production Task；不得调用 `image_gen`。
4. 任务完成后列出该 Source 的候选设定图，展示结果并等待用户确认；确认后选择设定图，再创建一次 Premise 拆解任务。
5. 拆解完成后，如需列出生成的设定资产，先读 `/api/v1/agent-docs/api/premise-asset.md`，再用 `request_api` 读取。

本地文件尚未成为 ready upload 时，引导用户在界面上传，不得虚构 UUID。API 细节以所读 Contract 为准。

# Guide：修改章节

用于修改章节标题、完整正文，或查看正文版本。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/chapter.md`。
2. 用 `request_api` 读取目标 Chapter、完整当前正文和最新 revision；需要比较时再读取正文版本列表。
3. 按用户目标更新标题，或提交完整替换后的正文与最新 revision。
4. 写入成功后重读目标 Chapter；发生冲突时重新读取并合并，不得原样重放旧请求。

仅讨论或起草时不要写入。API 细节以所读 Contract 为准。

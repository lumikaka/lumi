# Guide：维护设定资产

用于更新设定资产元数据、图片版本或当前图片。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise-asset.md`。
2. 用 `request_api` 读取目标资产、图片版本和最新 revision。
3. 按用户目标更新元数据；需要新图时调用 `image_gen` 后更新，或用 ready upload 创建图片版本；选择已有版本时提交最新 revision。`generate`/`restyle` 默认应用项目 `default_style`，`edit` 默认关闭它以保留来源画风；不得只为获取画风而读取 Premise，也不得在 Prompt 中重复画风。只改变渲染画风时使用 `operation=restyle`；改变主体、物件或背景内容时使用 `operation=edit`。两者都必须把目标资产 Reference 放在第一位，风格或细节参考放在后面；可以继续选择当前 Thread 中最近的历史冻结 Reference。必要的目标 Reference 不可用或校验失败时，不得改用 `generate`，也不得把降级结果写回目标资产。
4. 写入后重读目标资产；冲突时重新读取再决定是否重试。

成功写回的新图片会成为该 Tool Result 上的最新冻结 Reference，后续继续选择目标资产 UUID 即可。`image_gen` 成功只表示文件已生成；没有用户反馈或可验证的工具错误时，不得假设画面有问题并自行重复生成。不得把现有图片 UUID 当作新的生成输出，也不得在仅查看时修改资产。API 细节以所读 Contract 为准。

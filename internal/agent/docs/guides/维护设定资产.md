# Guide：维护设定资产

用于更新设定资产元数据、图片版本或当前图片。

## API 调用顺序和说明

1. 先用 `read_agent_doc` 阅读 `/api/v1/agent-docs/api/premise-asset.md`。
2. 用 `request_api` 读取目标资产、图片版本和最新 revision。
3. 按用户目标更新元数据；需要新图时调用 `image_gen` 后更新，或用 ready upload 创建图片版本；选择已有版本时提交最新 revision。`image_gen` 默认自动应用项目 `default_style`，不得只为获取画风而读取 Premise，也不得在 Prompt 中重复画风。用户要求仅转换现有图片画风时使用 `operation=restyle`，并把目标 Reference 放在第一位；可以继续选择当前 Thread 中最近的历史冻结 Reference。只有用户明确要求另一种画风时才设置 `use_default_style=false`。必要的目标 Reference 不可用或校验失败时，不得改用 `generate`，也不得把降级结果写回目标资产。
4. 写入后重读目标资产；冲突时重新读取再决定是否重试。

不得把现有图片 UUID 当作新的生成输出，也不得在仅查看时修改资产。API 细节以所读 Contract 为准。

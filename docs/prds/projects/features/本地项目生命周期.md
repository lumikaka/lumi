# 项目 — 本地项目生命周期

## overview

该 Feature 管理 local-first 项目的创建、发现、打开、关闭、重新定位和最近项目索引。项目目录是持久化边界：创建时建立项目文件、项目库和 `.lumi/project.lock`，打开时以项目 UUID 验证路径身份并取得操作系统锁；最近项目仅是可失效的本机发现记录。

同一进程可以并行打开多个项目。项目路由按 `project_uuid` 获取请求 lease；关闭某个项目会等待它自己的请求和 Runtime 安全停止，不影响其他项目。

## data_model

应用库使用 `recent_projects` 保存公开 UUIDv7、名称、最近 `root_path` 与时间。项目目录中的 `projects` 记录是身份事实源；目录路径变化后必须读取目标项目库并比较 UUID，不能只相信旧索引。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/project-defaults` | GET | 返回新建项目父目录和默认风格。 |
| `/api/v1/projects` | POST | 在 `parent_path` 下创建项目；目录候选由服务端原子占用。 |
| `/api/v1/open-projects` | GET | 返回当前已打开项目。 |
| `/api/v1/open-projects` | POST | 按 `root_path` 打开已有项目。 |
| `/api/v1/open-projects/:project_uuid` | PUT | 从最近索引幂等打开指定项目。 |
| `/api/v1/open-projects/:project_uuid` | DELETE | 关闭目标项目。 |
| `/api/v1/recent-projects` | GET | 返回最近项目索引。 |
| `/api/v1/recent-projects/:project_uuid` | PATCH / DELETE | 重新定位或忘记本机索引；删除索引不删除项目目录。 |

所有响应使用统一 JSON 信封；项目资源只暴露 UUIDv7。身份不匹配、格式过新、未打开和锁冲突使用稳定错误码。

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/` | 创建、打开与最近项目列表；不可用路径只在实际打开时报告。 |
| `/projects/:project_uuid/*` | 进入项目时幂等打开目标项目，不把浏览器标签页状态当作全局当前项目。 |

## others

`open_project:changed` 通过 `/api/v1/ws` 只广播公开 `{project_uuid, open}`。客户端据此失效相关查询，并在首次 join、重新 join 与窗口重新聚焦时通过 REST 校准。

# 项目 — 项目资料与绘本规格

## overview

该 Feature 管理项目名称、描述、生成语言与绘本规格。项目资料是项目级展示与生成输入，不包含 Chapter 正文、Premise 或模型选择；写入使用项目 revision 防止并发覆盖。

## data_model

`projects` 保存 `name`、`description`、`generation_language` 与非负 `revision`。`project_picture_book_profiles` 与项目一对一，保存页面宽高、页数与对应 revision；所有关系仅使用内部 `project_id`，响应只投影项目 UUIDv7。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid` | GET | 返回项目资料、统计与绘本规格。 |
| `/api/v1/projects/:project_uuid` | PATCH | 更新项目资料；按请求携带的 revision 执行乐观锁校验。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/overview/summary` | 展示与编辑项目资料、项目统计、绘本规格和关联配置入口。 |
| 新建项目 Dialog | 输入项目名称、语言、绘本规格和总体风格。 |

## others

整体风格作为 Premise 的初始默认值参与项目创建；后续视觉设定管理由 `premise_assets` 负责。

# 文件 — 项目文件资产管理

## overview

该 Feature 为项目提供受控文件上传和资产访问。上传采用暂存 → 校验 → Object 提交或去重 → 逻辑 File 创建的流程；业务域引用逻辑 File，而不是直接持有路径或 Object。File 可以更新展示元数据、移入回收站、恢复并按受控媒体 URL 读取内容。

## data_model

`upload_stashed` 保留接收状态、期限、预留 File UUID 和校验元数据。`file_objects` 以项目 SHA-256 去重并在 ready 后不可变；`files` 保存 purpose、来源、显示名、内部 Object 关联和 `deleted_at`。缩略图作为受控派生 File/Object，不改写原对象。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/asset-uploads` | POST | 创建上传暂存。 |
| `/api/v1/projects/:project_uuid/asset-uploads/:upload_uuid` | GET / DELETE | 读取或取消暂存上传。 |
| `/api/v1/projects/:project_uuid/asset-uploads/:upload_uuid/completions` | POST | 完成校验并提交逻辑 File。 |
| `/api/v1/projects/:project_uuid/assets` | GET | 列出项目逻辑资产。 |
| `/api/v1/projects/:project_uuid/assets/:asset_uuid` | GET / PATCH / DELETE | 读取、更新或逻辑删除资产。 |
| `/api/v1/projects/:project_uuid/assets/:asset_uuid/restorations` | POST | 恢复逻辑删除资产。 |
| `/api/v1/projects/:project_uuid/assets/:asset_uuid/thumbnails` | POST | 创建或重建受控缩略图。 |
| `/media/projects/:project_uuid/assets/:asset_uuid/content` | GET | 返回受控二进制内容。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/assets` | 浏览项目资产、状态、元数据、回收站与维护入口。 |
| Premise、漫画与 Chat 上传入口 | 复用受控上传和公开 File UUID；Chat 必须 finalize 后创建 `file` Reference，不把临时 Upload UUID 发给 Chat API。 |

## others

`content_url` 只服务属于该项目且可读取的 File。Chat 输入创建失败后未被引用的已 finalize File 由既有 GC 回收；一旦成为 Reference 的 `file_id` 或 `image_file_id`，永久删除与 GC 必须保留其 Object。响应不返回 Object 内部 ID、`key_path`、绝对路径或上传临时路径。

# 产品体验 - 从项目入口到持续创作工作台

## 模块职责

产品体验模块负责组织 Lumi 的全局导航、项目对话和项目内容画布，让用户在同一个稳定框架内完成进入项目、表达创作意图、查看上下文和检查产物。具体业务数据仍由故事生产与 AI 运行时模块负责。

## 职责边界

| 范围 | 说明 |
|---|---|
| 负责 | 全局侧栏、项目三栏工作台、模式导航、响应式降级、加载/空/错误/进行中等界面状态，以及跨区域的上下文连续性。 |
| 不负责 | 新增故事生产实体、改变生成任务语义、替代设定/章节/导出领域页面，或把本地账号改造成云端注册体系。 |

## 核心概念

### 项目是一级工作上下文

对话、设定、章节和作品都归属于项目。用户从左侧栏选择项目或对话后，工作台必须保留同一个项目上下文，不能要求用户重复选择项目。

### 对话是操作入口

中栏承接创作意图、追问、生成进度和结果反馈。项目已有内容不复制进对话，而是在右侧画布中持续可见并可被对话操作引用。

### 画布是事实与产物入口

右栏承载设定、章节和作品三个高频视图，并保留前往概览及低频管理能力的路径。画布展示 REST 数据事实源；实时消息只触发刷新。

## 与其他模块的关系

| 模块 | 关系 |
|---|---|
| 故事生产 | 画布复用 Premise 设定资产、Chapter、漫画图片和导出能力，不改变其状态机。 |
| AI 运行时 | 对话复用 Chat Thread、Turn、Workflow、附件和模型配置；运行状态回流到对话与侧栏。 |
| 本地项目管理 | 侧栏复用最近项目、打开项目、创建项目和移除最近记录的现有能力。 |
| 实时通信 | `/api/v1/ws` 发布的项目和任务事件用于失效对应 REST query，不作为画布事实源。 |

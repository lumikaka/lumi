# 设定资产 — 设定生成与资产化

## overview

该 Feature 将项目默认画风和用户输入沉淀为可追溯的 Premise source 批次、候选设定图和可复用资产。用户可导入或生成候选图、选择当前设定图、从候选图拆分角色/场景/道具/参考资产，并为资产追加和选择不可变视觉 variant。

对话式新项目还可把 Project Setup 中 included 的首页图片作为来源资产。它们复用原 File，不复制 Object：人物、场景和道具映射为对应 `asset_type`，画风与自动用途映射为 `reference`。来源、角色、位置和用户 instruction 写入 summary、tags 与追加事件。标题冲突按位置确定性追加“参考图 N”，绑定和导入位于同一事务，重试不重复创建 Asset 或 Variant。

候选图历史按服务端分页，页面只批量读取已加载 source 页关联的 setting images，避免全项目历史全量读取和 N+1 请求。

## data_model

`premise_profiles` 保存项目默认画风和 current 指针。`premise_sources` 冻结输入、样式、Provider/模型和参数；`premise_setting_images` 关联 File。`premise_assets` 使用 title、type、tag、位置和 current variant 表达当前业务资源，Variant 通过版本号保留来源和裁剪快照。来源 Asset 由 `project_creation_reference_files.premise_asset_id` 反向保护；关联 Asset 在回收站时，下一次 YOLO 重试恢复同一记录。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/premise` | GET / PATCH | 读取或更新 Premise Profile。 |
| `/api/v1/projects/:project_uuid/premise-sources` | GET / POST | 分页读取或创建 source 批次。 |
| `/api/v1/projects/:project_uuid/premise-sources/:source_uuid` | PATCH | 更新 source 的允许状态。 |
| `/api/v1/projects/:project_uuid/premise-sources/:source_uuid/setting-generations` | POST | 创建候选设定图任务。 |
| `/api/v1/projects/:project_uuid/premise-setting-images` | GET / POST | 批量读取或导入候选设定图。 |
| `/api/v1/projects/:project_uuid/premise-setting-images/:setting_image_uuid/selections` | POST | 选择当前候选设定图。 |
| `/api/v1/projects/:project_uuid/premise-setting-images/:setting_image_uuid/breakdowns` | POST | 把候选图拆分为独立资产。 |
| `/api/v1/projects/:project_uuid/premise-assets` | GET / POST | 列出或创建 Premise 资产。 |
| `/api/v1/projects/:project_uuid/premise-assets/:premise_asset_uuid` | GET / PATCH | 读取或更新资产元数据。 |
| `/api/v1/projects/:project_uuid/premise-assets/:premise_asset_uuid/variants` | GET / POST | 读取或追加 Variant。 |
| `/api/v1/projects/:project_uuid/premise-assets/:premise_asset_uuid/variants/:variant_uuid/selections` | POST | 切换 current variant。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/premise` | 编辑默认画风、浏览 source 历史、候选设定图与资产工作区。 |
| ChatArea 通用对话 | 可预选或多选 Premise Asset Reference，并通过受控项目 API 生成、引用或整理设定资产。 |

## jobs

| Job / Worker | 触发条件 | 策略 |
|---|---|---|
| `premise_setting_generation` | 用户请求候选设定图或 YOLO v6 带 included 创建参考 | 普通任务冻结 source、Prompt、模型和参数；带引用任务额外冻结图片计划和合成器，生成/复用一个带标签参考板并作为唯一图片输入。图片不可用或 Provider 拒绝输入时明确失败，不降级。 |
| `premise_asset_breakdown` | 用户将候选图拆分为资产 | 对每个生成结果创建独立资产/Variant；同名命中来源型创建参考时记录 checkpoint/event 并保持用户原图为 current。 |

## others

模型与 Prompt 由创建时快照决定。带创建参考时追加 `setting_reference_usage`：列出角色、标题和 instruction，并禁止复制参考板网格、标签和留白；无引用任务不追加，保持旧 Prompt。Chat `image_gen` 结果不绑定 Scene 或单一 subject，可显式写入任意合法 Premise Asset；创建/更新仍须指定目标 UUID 与 `expected_revision`，事件 provenance 保存全部来源 Reference UUID 数组。候选与资产 API 只返回公开 UUID 和受控 File 投影，不返回内部 file/object ID 或路径。

Section 自动选择候选除标题外还带 `asset_type`、最多 240 字的 summary 和可选 `reference_role`；整个候选片段最多 24,000 Unicode 字符。明确选择优先级和每页最多 12 个 Premise File 的限制不变，首版不会把所有 style Asset 强制塞入每页。

# Lumi — PRD 索引

Lumi 的产品需求按 domain 组织。每个 Feature 是可独立复制的业务能力包；页面、按钮、单个 API 和 worker 作为 Feature 的实现组成部分记录，不单独拆分。

| Domain | 文档 | 说明 |
|---|---|---|
| 产品体验 | [`product_experience/overview.md`](product_experience/overview.md) | 统一全局导航、项目对话与项目内容画布，形成稳定的三栏创作工作台。 |
| 故事生产 | [`story_production/overview.md`](story_production/overview.md) | 管理 Premise 设定、Chapter 生命周期、章节漫画生产、快照恢复与可审计导出。 |
| AI 运行时 | [`ai_runtime/overview.md`](ai_runtime/overview.md) | 解析并冻结分层模型配置，并提供项目 AI 调用的安全审计与用量观测。 |

# 导出 — 漫画导出与短期交付

## overview

该 Feature 从项目或 Chapter 的 active Section current ready 图片创建原图 ZIP 或 A4 PDF。用户先读取就绪度；范围内必须至少有一张 ready `body` 才可导出，只有封面或封底图片不足以导出。任一已存在封面、正文页或封底缺图都会进入 `missing_sections`、使 `complete=false`，此时必须显式授权部分导出。创建事务再次复检并冻结图片、页面角色、缺图页、范围、格式和 snapshot hash，避免预检与执行之间的竞态。

导出条目依 Chapter 和 `section_no` 保持装订顺序，同时为每个 Chapter 的 active `body` 从 1 起计算 `body_page_no`。v6 ZIP 分别命名为 `<chapter>/front-cover.ext`、`<chapter>/pages/page-%03d.ext` 和 `<chapter>/back-cover.ext`；历史 v1–v5 ZIP 仍按旧 `sections/section-%03d` 布局读取。PDF 中有图的封面和封底各自独占一张 A4，正文页依绘本比例继续使用单页或双页布局，项目范围不跨 Chapter 配对。

相同范围、格式和快照优先复用未到期 canonical ready 产物。ZIP/PDF 仅保留 7 天，不自动下载，也不允许用户指定服务器保存路径；用户通过 `download_url` 主动下载。

## data_model

`comic_exports` 保存 scope、format、冻结快照、状态、保留期、到期、大小、SHA-256 和受控相对路径。v6 快照在 `entries[]` 和 `missing_sections[]` 中冻结 `page_role` 与 `body_page_no`，并保留 `missing_section_uuids` 兼容字段；历史 PDF v5 缺少页面角色时按 `body` 兼容。PDF 下载名使用项目标题，Chapter 范围追加安全清理后的 chapter code；内部路径使用 Export UUID 隔离并发。`production_task_runs.kind=comic_export` 保存执行状态和缺图计数快照。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/comic-exports/readiness?scope=chapter&chapter_uuid=:chapter_uuid` | GET | 返回项目或 Chapter 导出就绪度；`missing_sections[]` 包含 `page_role` 和正文页的 `body_page_no`，`can_export` 要求至少一张 ready 正文页。 |
| `/api/v1/projects/:project_uuid/comic-exports` | GET | 按 page、scope、chapter、task、snapshot、format、status 读取未到期导出历史。 |
| `/api/v1/projects/:project_uuid/comic-exports` | POST | 创建 ZIP/PDF 导出；缺图时要求显式 `allow_missing_images`。 |
| `/media/projects/:project_uuid/comic-exports/:export_uuid/content` | GET | 下载未到期 ready 产物，支持 Range、ETag 与安全文件名。 |

到期但尚未清理时下载返回 `410 comic_export_expired`，清理后返回 404。所有 JSON 响应使用统一信封，Export 投影只在未到期 ready 状态提供 `download_url`。

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/overview/exports` | 项目和 Chapter 范围的导出历史、筛选和分页。 |
| `/projects/:project_uuid/comic` 与 Chapter 工作台 | 进入统一导出 Dialog。 |
| 单次导出 Dialog | 显式选择“原图 ZIP”或“A4 PDF”，展示范围、就绪度、按“封面 / 正文第 N 页 / 封底”标记的缺图、保留期、到期时间、任务状态和下载入口。 |

## jobs

| Job / Worker | 触发条件 | 策略 |
|---|---|---|
| `comic_export` | 用户确认格式和完整/部分导出 | 冻结图片、页面角色和格式；流式写 ZIP 或按封面/正文/封底规则渲染 PDF，原子发布并记录 hash。 |
| `lumi_comic_export_cleanup_v1` | 项目 Runtime 启动及其后每小时 | 删除到期终态 Export、任务图、登记产物和受控孤儿 `.part`；失败项下轮幂等重试。 |

## others

兼容旧 `output_file_id` 时，到期先使旧 File 逻辑删除，再经 export-only GC 与引用复检回收独占 Object。新导出永不写入 Asset Store。

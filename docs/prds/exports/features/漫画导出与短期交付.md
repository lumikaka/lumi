# 导出 — 漫画导出与短期交付

## overview

该 Feature 从项目或 Chapter 的 active Section current ready 图片创建原图 ZIP 或 A4 PDF。用户先读取就绪度；零可用图禁止导出，缺图时必须显式授权部分导出。创建事务再次复检并冻结图片、范围、格式和 snapshot hash，避免预检与执行之间的竞态。

相同范围、格式和快照优先复用未到期 canonical ready 产物。ZIP/PDF 仅保留 7 天，不自动下载，也不允许用户指定服务器保存路径；用户通过 `download_url` 主动下载。

## data_model

`comic_exports` 保存 scope、format、冻结快照、状态、保留期、到期、大小、SHA-256 和受控相对路径。PDF 下载名使用项目标题，Chapter 范围追加安全清理后的 chapter code；内部路径使用 Export UUID 隔离并发。`production_task_runs.kind= comic_export` 保存执行状态和缺图计数快照。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/comic-exports/readiness?scope=chapter&chapter_uuid=:chapter_uuid` | GET | 返回项目或 Chapter 导出就绪度。 |
| `/api/v1/projects/:project_uuid/comic-exports` | GET | 按 page、scope、chapter、task、snapshot、format、status 读取未到期导出历史。 |
| `/api/v1/projects/:project_uuid/comic-exports` | POST | 创建 ZIP/PDF 导出；缺图时要求显式 `allow_missing_images`。 |
| `/media/projects/:project_uuid/comic-exports/:export_uuid/content` | GET | 下载未到期 ready 产物，支持 Range、ETag 与安全文件名。 |

到期但尚未清理时下载返回 `410 comic_export_expired`，清理后返回 404。所有 JSON 响应使用统一信封，Export 投影只在未到期 ready 状态提供 `download_url`。

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/overview/exports` | 项目和 Chapter 范围的导出历史、筛选和分页。 |
| `/projects/:project_uuid/comic` 与 Chapter 工作台 | 进入统一导出 Dialog。 |
| 单次导出 Dialog | 显式选择“原图 ZIP”或“A4 PDF”，展示范围、就绪度、缺图、保留期、到期时间、任务状态和下载入口。 |

## jobs

| Job / Worker | 触发条件 | 策略 |
|---|---|---|
| `comic_export` | 用户确认格式和完整/部分导出 | 冻结图片和格式；流式写 ZIP 或渲染 PDF，原子发布并记录 hash。 |
| `lumi_comic_export_cleanup_v1` | 项目 Runtime 启动及其后每小时 | 删除到期终态 Export、任务图、登记产物和受控孤儿 `.part`；失败项下轮幂等重试。 |

## others

兼容旧 `output_file_id` 时，到期先使旧 File 逻辑删除，再经 export-only GC 与引用复检回收独占 Object。新导出永不写入 Asset Store。

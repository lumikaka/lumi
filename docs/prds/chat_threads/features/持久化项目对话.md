# 对话线程 — 持久化项目对话

## overview

该 Feature 提供可恢复的项目 Agent 对话。首次提交创建 Thread 和首个 Turn；执行过程把 Run、消息 Item 和事件持久化，页面可以分页浏览线程、cursor 回溯消息和事件，并在重新打开、重连或窗口重新聚焦时从 REST 重建状态。

## data_model

Thread 固定 `project_id`、`scope`、可选 `scene`/`subject_uuid` 和冻结模型。Turn 按 queue sequence 排队，Run 保存一次执行，Item 按 Thread 内 sequence 排列；`chat_events` 仅追加，不允许把实时 payload 作为历史来源。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chat_threads` | GET / POST | 页码读取或创建 Thread。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid` | GET | 读取单个 Thread。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/turns` | GET / POST | 读取 Turn 或创建新的用户输入。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/items?before=&after=&limit=` | GET | cursor 读取对话 Item。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/events?after=&limit=` | GET | cursor 读取脱敏事件流。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| 项目 ChatArea | 线程列表、草稿对话、按 Turn 分组的消息流和状态恢复。 |
| `/projects/:project_uuid/premise` | 复用项目 Thread 列表与对话详情，按绑定场景展示入口。 |

## others

列表使用页码分页，Item 与 Event 使用 opaque cursor。客户端收到 `chat:*` 变更提示后失效相应查询，并在首次 join、重新 join 与窗口重新聚焦时 REST 校准。

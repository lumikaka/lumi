# 对话线程 — 对话工具与多模态交互

## overview

该 Feature 把 Agent 工具调用、用户选择题和图片引用变成可恢复的对话交互。工具先写入 `agent_tool_executions` 意图和幂等键，再由受控项目 API 或图片生成能力执行；用户输入请求通过持久状态暂停和恢复 Run，不把临时浏览器状态当作事实源。

对话和 Follow-up 可引用最多允许数量的受控图片 File。普通新 Turn 不继承旧图片；Steering 只可继承当前活动 Turn 最近一组，不能跨 Thread 或任意历史隐式复用。

## data_model

`chat_user_input_requests` 关联 Thread、Run、Turn、Item 和 Tool call UUID，保存问题、选项、回答与 `pending|answered|resuming|resumed|cancelled` 状态。`agent_tool_executions` 保存工具名、目标 UUID、合法 JSON 参数、幂等键、执行状态和脱敏结果。图片引用表以内部 item/follow-up/file 外键关联，公开投影只含 File UUID、元数据与受控 `content_url`。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/user_input_requests` | GET | 读取 Thread 的用户输入请求。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/user_input_requests/:request_uuid/responses` | POST | 提交单选或多选回答。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/user_input_requests/:request_uuid/cancellations` | POST | 取消待回答请求。 |
| `/api/v1/projects/:project_uuid/asset-uploads` | POST | 为图片引用创建受控上传。 |
| `/api/v1/projects/:project_uuid/asset-uploads/:upload_uuid/completions` | POST | 完成上传并获得可引用 File。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| ChatArea 工具与输入项 | 渲染工具状态、单选/多选请求、图片缩略图、上传错误和重试。 |
| Premise 引用场景 | 选择或粘贴设定参考图，并以显式工具结果呈现资产变更。 |

## others

对外 Item metadata、事件与工具结果递归移除内部 `id`、路径、Authorization、cookie、credential、password、API key 和 token。业务修改必须通过对应项目领域服务，不允许 Agent 直接执行任意文件或数据库操作。

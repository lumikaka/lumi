# 对话线程 — 对话工具与多模态交互

## overview

该 Feature 把 Agent 工具调用、用户选择题和多资源 Reference 变成可恢复的对话交互。工具先写入 `agent_tool_executions` 意图和幂等键，再由受控项目 API 或图片生成能力执行；用户输入请求通过持久状态暂停和恢复 Run，不把临时浏览器状态当作事实源。

初始 Turn、Steering 和 Follow-up 均可携带最多 16 个 `file`、`premise_asset` 或 `comic_section` Reference。Reference 只属于对应用户输入；普通新 Turn 从空集合开始，历史 Reference 不会重新注入。当前 Turn 中同一资源再次出现时，以最新 User Item 的冻结快照为准。

## data_model

`chat_user_input_requests` 关联 Thread、Run、Turn、Item 和 Tool call UUID，保存问题、选项、回答与 `pending|answered|resuming|resumed|cancelled` 状态。`agent_tool_executions` 保存工具名、目标 UUID、合法 JSON 参数、幂等键、执行状态和脱敏结果。`chat_context_references` 以内部 owner/资源/File 外键关联，公开投影只含资源类型、UUID、位置、`image_available` 和紧凑快照。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/user_input_requests` | GET | 读取 Thread 的用户输入请求。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/user_input_requests/:request_uuid/responses` | POST | 提交单选或多选回答。 |
| `/api/v1/projects/:project_uuid/chat_threads/:thread_uuid/user_input_requests/:request_uuid/cancellations` | POST | 取消待回答请求。 |
| `/api/v1/projects/:project_uuid/asset-uploads` | POST | 为图片引用创建受控上传。 |
| `/api/v1/projects/:project_uuid/asset-uploads/:upload_uuid/completions` | POST | 完成上传并获得可引用 File。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| ChatArea 工具与输入项 | 统一 Reference Strip 与 Picker；Premise Asset 多选、按 Chapter 选择 Comic Section、图片先 finalize 为 File Reference。 |
| Premise / Comic 入口 | 预选一个资源 Reference，不创建绑定资源的特殊 Thread。 |

## others

`image_gen.reference_uuids` 是必填数组，可为空，最多按顺序选择 4 个当前 Turn 中具有冻结图片的 Reference；历史、未知、重复或无图项返回可修复 validation 错误。结果使用普通 Chat 图片用途，并记录来源 Reference UUID、类型和实际 File UUID。对外 Item metadata、事件与工具结果递归移除内部 `id`、路径、Authorization、cookie、credential、password、API key 和 token。

# 章节 — 章节创作与正文版本

## overview

该 Feature 管理 Chapter 的编号、顺序、标题、正文编辑和批量导入。正文不会原地覆盖：每次编辑都创建新的 `chapter_stories` 版本，`current_story_id` 仅切换到已提交的新版本，因此历史可审计并能为 AI 任务提供稳定输入。

## data_model

Chapter 使用项目内唯一的 active `chapter_code`、卷章编号和排序。正文版本通过来源批次和来源项保留人工录入或文件导入出处；外部导入文件只经 `files` 服务持久化，Story 代码不直接写入资产目录。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chapters?state=active|trashed` | GET | 按生命周期读取 Chapter 列表。 |
| `/api/v1/projects/:project_uuid/chapters` | POST | 创建 Chapter。 |
| `/api/v1/projects/:project_uuid/chapter-imports` | POST | 导入多个章节和正文来源。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid` | GET / PATCH | 读取或更新 Chapter 基础信息。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/current-story` | GET / PUT | 读取或追加并切换当前正文。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/stories` | GET | 查询 Chapter 正文版本历史。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/chapters` | 浏览、创建、导入和排序 Chapter。 |
| `/projects/:project_uuid/chapters/:chapter_uuid` | 编辑 Chapter 和当前正文，查看关联生成状态。 |

## others

所有正文、来源和关联资源对外只传 UUIDv7；内部 source/file/actor 关系不泄露内部 ID。

# 页面 / 画面段落 — 漫画分镜与图片生产

## overview

该 Feature 将 Chapter 当前正文与 Premise 资产转化为有序 Section、Storyboard 和 Image Variant。普通绘本形式面向用户称“页面、页面脚本、页面图片版本”，并以 `front_cover|body|back_cover` 表达可选封面、正文页和可选封底；条漫 `vertical_strip` 称“画面段落、分镜脚本、页面图片版本”，且只允许 `body`。

用户可手工创建、编辑、排序或删除 Section，维护脚本和页面图片版本，也可触发脚本/图片生成。服务端固定封面为首页、封底为末页，正文页只在中间重排。生成时冻结输入、Prompt、模型和 Section Premise 选择，完成后只追加 Variant 并由用户选择 current 版本。Chapter 级 AI Storyboard 生成与覆盖只比较、新增或逻辑删除 `body`，不覆盖已有封面或封底。

## data_model

Section 通过 current storyboard/image 指针投影当前画面，历史 Variant 不覆盖。`comic_sections.page_role` 非空并默认 `body`；active 封面和封底分别在同一 comic state 内最多一个。创建封面时自动放到首位，新建正文页插在封底之前，创建封底时自动放到末位；角色转换也会归一整本顺序。

普通绘本的全空 comic state 必须先建立 `body`；创建 `front_cover|back_cover` 前必须已有 active 正文页，删除唯一 `body` 或把它改为特殊角色也会被拒绝，因此普通绘本一旦建立当前页面序列，就始终至少包含一张正文页。`vertical_strip` 不支持特殊角色，但允许删除最后一个画面段落回到 empty。

`chapter_comic_states.status` 表示整体生产状态：所有实际存在的页面都参与 `storyboarded` 和图片完整度判定，`storyboarded` 与 `ready` 都另外要求至少一个 active `body`。因此只有封面既不会变为 storyboarded，也不会变为 ready；已创建但缺图的可选封面或封底也会使整本绘本未 ready。Section Premise 只引用可用的 Premise 资产公开 UUID 和受控 File。生成与任务状态由 `production_task_runs` 或 `workflows` 管理，本域保存业务 Variant 和冲突语义。

新建 Section 图片任务使用输入快照 v5 冻结 `page_role` 与对应的完整 Prompt：封面、正文页和封底分别组合 `chapter/cover_before_image`、`chapter/before_image` 与 `chapter/back_cover_before_image`。封底规则不继承正文句数、互动提问、无字或漫画分格约束，也不会自行添加条码、作者或宣传语。若生成期间页面角色发生变化，提交结果时拒绝旧角色图片；v1–v4 历史任务继续按无角色的旧路径完成。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic` | GET | 返回漫画状态与 Premise 资产就绪投影。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections` | GET / POST | 读取装订顺序或创建 Section；请求可传 `page_role`，缺省为 `body`，响应回传角色；普通绘本创建封面/封底前必须已有 active 正文页。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-section-order` | PUT | 推荐提交当前全部 active `body` 的 `section_uuids` 原子重排；为兼容旧客户端也接受包含全部 active 页面的一份完整列表，但只提取正文顺序并重新固定封面/封底，响应返回归一后的全部 Section。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid` | GET / PATCH / DELETE | 读取、以 `expected_revision` 更新内容或 `page_role`、或逻辑删除 Section；角色冲突、条漫特殊页、非法角色，以及普通绘本删除唯一正文页或把它改为特殊页都会被拒绝。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/storyboard-variants` | GET / POST | 读取或追加分镜 Variant。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/storyboard-variants/:variant_uuid/selections` | POST | 选择当前分镜。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/images` | POST | 导入 Section 图片。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-variants` | GET | 读取图片 Variant、公开资产和 Section Premise。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-variants/:variant_uuid/selections` | POST | 选择当前图片。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-generations` | POST | 创建 Section 图片生成。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-storyboard-generations` | POST | 创建 Chapter 正文页脚本生成，`max_section_count` 为 1–24；封面和封底不进入生成、比较、覆盖或结果 Section 列表。 |
| `/api/v1/projects/:project_uuid/workflows/:workflow_uuid/conflict-resolutions` | POST | 解决漫画分镜 Workflow 冲突。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/comic` | 浏览当前 Chapter 漫画、Section 装订顺序、页面角色、脚本和图片状态。普通绘本显示“封面 / 正文第 N 页 / 封底”，创建/编辑入口按正文存在性和特殊角色唯一性禁用非法选项；封面和封底不参与拖拽排序。 |
| `/projects/:project_uuid/chapters/:chapter_uuid` | 在 Chapter 工作台创建分镜生成、查看 Premise 资产警告和 Section 入口。 |
| Section 图片详情 | 展示 current/candidate、版本、来源、生成摘要、Provider/模型和 Premise 引用；候选图可设为当前。 |

## jobs

| Job / Worker | 触发条件 | 策略 |
|---|---|---|
| `comic_storyboard_generation` | 用户请求 Chapter 正文页脚本 | 冻结 `max_section_count`、Story、Prompt、模型和规划；只投影 `body`，重试不重新解析输入。 |
| `comic_image_generation` | 用户请求 Section 图片 | 冻结 Section、`page_role`、角色化 Prompt、Premise 参考与图片模型；提交时复检角色，成功后追加图片 Variant 并刷新漫画状态。 |

## others

活动生成期间禁止与其冲突的快照恢复。实时消息只含公开 Chapter/Section/Variant UUID 和必要状态，客户端据此失效 REST 查询。

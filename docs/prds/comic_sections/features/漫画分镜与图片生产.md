# 漫画段落 — 漫画分镜与图片生产

## overview

该 Feature 将 Chapter 当前正文与 Premise 资产转化为有序漫画 Section、分镜和图片。用户可手工创建、编辑、排序或删除 Section，维护分镜和图片 Variant，也可触发分镜/图片生成。生成时冻结输入、Prompt、模型和 Section Premise 选择，完成后只追加 Variant 并由用户选择 current 版本。

## data_model

Section 通过 current storyboard/image 指针投影当前画面，历史 Variant 不覆盖。`chapter_comic_states.status` 表示整体生产状态；Section Premise 只引用可用的 Premise 资产公开 UUID 和受控 File。生成与任务状态由 `production_task_runs` 或 `workflows` 管理，本域保存业务 Variant 和冲突语义。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic` | GET | 返回漫画状态与 Premise 资产就绪投影。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections` | GET / POST | 读取或创建 Section。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-section-order` | PUT | 原子重排 active Section。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid` | GET / PATCH / DELETE | 读取、更新或逻辑删除 Section。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/storyboard-variants` | GET / POST | 读取或追加分镜 Variant。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/storyboard-variants/:variant_uuid/selections` | POST | 选择当前分镜。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/images` | POST | 导入 Section 图片。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-variants` | GET | 读取图片 Variant、公开资产和 Section Premise。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-variants/:variant_uuid/selections` | POST | 选择当前图片。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-generations` | POST | 创建 Section 图片生成。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-storyboard-generations` | POST | 创建 Chapter 分镜生成，`max_section_count` 为 1–24。 |
| `/api/v1/projects/:project_uuid/workflows/:workflow_uuid/conflict-resolutions` | POST | 解决漫画分镜 Workflow 冲突。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| `/projects/:project_uuid/comic` | 浏览当前 Chapter 漫画、Section 顺序、分镜和图片状态。 |
| `/projects/:project_uuid/chapters/:chapter_uuid` | 在 Chapter 工作台创建分镜生成、查看 Premise 资产警告和 Section 入口。 |
| Section 图片详情 | 展示 current/candidate、版本、来源、生成摘要、Provider/模型和 Premise 引用；候选图可设为当前。 |

## jobs

| Job / Worker | 触发条件 | 策略 |
|---|---|---|
| `comic_storyboard_generation` | 用户请求 Chapter 分镜 | 冻结 `max_section_count`、Story、Prompt、模型和规划；重试不重新解析输入。 |
| `comic_image_generation` | 用户请求 Section 图片 | 冻结 Section、Premise 参考与图片模型；完成后追加图片 Variant 并刷新漫画状态。 |

## others

活动生成期间禁止与其冲突的快照恢复。实时消息只含公开 Chapter/Section/Variant UUID 和必要状态，客户端据此失效 REST 查询。

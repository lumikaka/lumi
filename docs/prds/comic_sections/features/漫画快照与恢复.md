# 漫画段落 — 漫画快照与恢复

## overview

该 Feature 将 Chapter 当前漫画状态冻结为不可变快照，并允许用户在确认后恢复。列表只显示版本、原因、来源、Section 数和时间；详情才安全投影有序分镜、当前图片和 Premise 参考，同时显式标注 `ready`、`missing` 或其他媒体不可用状态。

恢复不是把旧 JSON 直接暴露或修改历史 Variant，而是由服务端校验快照 schema、Chapter 当前状态和活动任务后恢复可编辑当前状态。存在活动生成时返回稳定冲突，避免生成结果写入被恢复的旧状态。

## data_model

`comic_chapter_snapshots` 保存 Chapter comic state、version_no、reason、source、schema version、快照 JSON/hash 和时间。公开摘要只包含 UUIDv7、版本、原因、来源、Section 数和创建时间；详情中的媒体只包含可解析的公开资产投影。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-snapshots` | GET | 返回 `{items}` 快照摘要列表。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-snapshots/:snapshot_uuid` | GET | 返回单个可预览快照详情。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-snapshots/:snapshot_uuid/restorations` | POST | 校验并恢复快照；活动生成时返回 `production_snapshot_restore_blocked`。 |

## ui

| 页面 / 入口 | 说明 |
|---|---|
| Chapter 快照 Dialog | 宽屏为版本列表与详情，窄屏纵向排列；详情失败时禁用恢复。 |
| 恢复确认 | 显示版本和 Section 数，提交期间禁止关闭与重复提交。 |

## others

兼容旧快照时服务端可按 schema version 回退读取，但不向客户端暴露内部 JSON/hash。恢复成功发布 `comic:snapshot_restored`，前端重新读取漫画、任务和导出就绪度。

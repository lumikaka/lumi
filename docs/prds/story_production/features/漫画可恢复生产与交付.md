# 故事生产 — 漫画可恢复生产与交付

## overview

该 Feature 把 Chapter 漫画从分镜生成到原图 ZIP 或 A4 PDF 交付组织成一条可检查、可追溯、可恢复的生产流程。

核心流程如下：

1. 用户创建漫画分镜任务时可设置 `max_section_count`，合法范围为 1–24，默认 6。服务端把该值、确定性的段落规划和最终 Prompt 一起冻结到任务快照；重试沿用原快照，旧任务缺少该字段时按 6 解释。
2. Chapter 工作台读取漫画状态。只有存在 current variant 且其 File 未删除、object 状态为 `ready` 的 active Premise 资产才计入 `premise_asset_count`；计数为 0 时显示非阻断警告并允许直接进入 Premise 工作区。
3. 关键漫画变更追加 Chapter 快照。历史列表只返回摘要；用户选择后才请求详情，预览按 `section_no` 稳定排序，缺失或不可用的当前图片和 Premise 参考图显示占位状态。
4. 恢复必须先成功加载详情并经二次确认。存在 active `story_chapter_generation`、`comic_storyboard_generation` 或 `comic_image_generation` 时拒绝恢复；成功恢复后刷新 Section、图片、快照和任务，并选中恢复后的首个 Section。
5. 所有新建 Project / Chapter 导出入口先打开统一的单次导出 Dialog 并计算就绪度：至少一张图片可用时必须显式选择“原图 ZIP”或“A4 PDF”，完整导出选择后才创建任务；有缺图时同时列出缺失 Section 并要求确认部分导出；零可用图时只显示阻断信息。任务创建事务内再次检查并冻结相同状态，避免预检与排队之间的竞态。
6. 导出 Dialog 覆盖检查、缺图确认、排队、运行、完成、失败和取消状态。关闭排队或运行中的 Dialog 只隐藏界面，任务继续执行；再次点击同一资源的导出入口恢复活动任务。关闭终态 Dialog 后，再次点击按当前内容创建新导出。
7. ready、failed 和 cancelled 导出均从进入终态起保留 7 天。Dialog 与列表显示格式、固定保留期和精确到期时间；到期项立即从读取投影隐藏，后台随后删除 Export、任务、事件、日志和 ZIP/PDF，不展示 `expired` 历史。
8. Premise 批次和漫画导出历史均在服务端分页。批次页只批量读取该页 source UUID 对应的 setting images；项目与 Chapter 导出在筛选后分别分页。
9. Section 当前图和候选图共享图片详情 Dialog。详情只从生成快照白名单投影 Provider、模型、状态和模型来源，并结合公开 Asset 与 Section Premise 摘要展示，不渲染完整 `input_snapshot`。

Chapter 和 Project scope 使用相同就绪度规则。ZIP 按确定顺序保留 ready 原图；PDF 固定为 A4 竖版，第 1 页使用项目名作为文本封面，Chapter scope 另显示章节编号与标题。横版与互动绘本页面上下两张、条漫左右两张，方形和其他竖版每页一张；图片完整居中、不裁剪、不旋转、不拉伸。Project PDF 不跨 Chapter 配对，下一个 Chapter 必须从新页开始。部分导出跳过缺图 Section，并按剩余顺序排版。

快照 hash 是包含格式的幂等身份。ZIP 保持 v4 快照兼容，PDF 使用 v5 快照冻结封面、布局、Chapter 边界、图片 MIME 与尺寸；相同格式和快照只复用尚未到期的 canonical 产物，复用不延长原到期时间。ZIP/PDF 只保存到项目内 `exports/`，不写入 Asset Store，也不要求或允许用户选择保存位置；任务完成后由用户通过 Export 的 `download_url` 显式下载，不自动触发下载。

## data_model

- `chapter_comic_states` 保存 Chapter 当前漫画状态；Premise 就绪计数是查询投影。
- `comic_sections` 通过 current variant 指针表达当前分镜和图片，历史 variant 不覆盖。
- `comic_chapter_snapshots` 保存 schema version、Chapter 摘要、Section 顺序、分镜内容、当前图片 UUID 和 Premise 参考 UUID；表内 JSON/hash 不从 API 暴露。
- `comic_exports` 保存 scope、`zip | pdf` 格式、冻结快照、hash、状态、`retention_days`、`expires_at`、`byte_size`、`content_sha256` 和项目根相对路径。`output_file_id` 仅兼容升级前双写到 Asset Store 的导出，新导出始终为空。
- `task_runs` 的 `comic_storyboard_generation` 冻结 `max_section_count`；`production_task_runs` 的 `comic_export` 冻结导出计数和缺失 Section UUID。
- `premise_sources` 与 `premise_setting_images` 构成批次输入和候选总览图历史；source 按创建时间与内部 ID 稳定分页，对外只返回 UUIDv7。

公开快照摘要字段为 `uuid`、`version_no`、`reason`、`source`、`section_count`、`created_at`。详情增加 `schema_version`、Chapter 的 `uuid/chapter_code/title`，以及排序后的 Section `uuid/section_no/title/storyboard_md/current_image/premise_reference`。媒体项以 `status` 表达 `ready`、`missing` 或其他不可用状态，只有可解析时才附带公开 asset。

## api

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic` | GET | 返回漫画状态和 `has_premise_assets` / `premise_asset_count` 投影。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-storyboard-generations` | POST | 创建分镜生成任务；`max_section_count` 可省略，或为 1–24。 |
| `/api/v1/projects/:project_uuid/premise-sources?page=&per_page=` | GET | 返回 `{items,pagination}` 批次历史，按 `created_at DESC,id DESC` 排序但不暴露 ID。 |
| `/api/v1/projects/:project_uuid/premise-setting-images?source_uuid=:uuid` | GET | 可重复 `source_uuid` 批量读取可见批次所需候选图，避免全量/N+1 HTTP 读取。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-sections/:section_uuid/image-variants` | GET | 返回候选图、公开 Asset、Section Premise 和白名单生成摘要；不要求 UI 渲染完整输入快照。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-snapshots` | GET | 返回 `{items}` 摘要列表，不返回内部 JSON/hash。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-snapshots/:snapshot_uuid` | GET | 返回单个可预览快照详情，安全投影媒体可用状态。 |
| `/api/v1/projects/:project_uuid/chapters/:chapter_uuid/comic-snapshots/:snapshot_uuid/restorations` | POST | 恢复快照；活动生成存在时返回 `production_snapshot_restore_blocked` 冲突。 |
| `/api/v1/projects/:project_uuid/comic-exports/readiness?scope=chapter&chapter_uuid=:chapter_uuid` | GET | 返回章节就绪度。`scope=project` 时省略 Chapter UUID。 |
| `/api/v1/projects/:project_uuid/comic-exports` | POST | 创建导出；`format` 支持 `zip` / `pdf`，省略时兼容为 `zip`；部分导出必须显式传 `allow_missing_images: true`。响应 `data` 为 `{export,task}`，Export 创建时即包含格式与 `filename`。 |
| `/api/v1/projects/:project_uuid/comic-exports?page=&per_page=&scope=&chapter_uuid=&task_uuid=&snapshot_hash=&format=&status=` | GET | 在 scope、Chapter、任务 UUID、快照 hash、格式和状态精确筛选后返回 `{items,pagination}`；只返回未到期记录，用于导出历史分页、活动任务恢复和同格式 canonical ready 产物解析。 |
| `/media/projects/:project_uuid/comic-exports/:export_uuid/content` | GET | 下载未到期的 ready ZIP/PDF，以 `application/zip` 或 `application/pdf` 返回并支持 Range、ETag 与安全文件名；精确到期但尚未清理时返回 `410 comic_export_expired`，清理后返回 404。 |

所有 JSON 响应遵守统一信封，字段使用 `snake_case`。Export 投影包含 `download_url`、`expires_at`、`retention_days`、`byte_size` 和 `content_sha256`；只有未到期 ready 项具有 `download_url`。零可用图使用 `production_export_empty`；缺图但未授权部分导出使用 `production_export_incomplete`。所有路径参数和 payload 引用只接受 UUIDv7。

| `/projects/:project_uuid/overview/exports` | Project 与 Chapter 新建按钮进入统一 Dialog；历史列表继续维护独立分页、服务端总数和直接下载。 |
| 单次导出 Dialog | 无默认格式；展示“原图 ZIP”和“A4 PDF”可访问选择卡片，选择后才能创建完整或部分导出。运行阶段展示范围、格式、文件名、快照 hash / 版本、可导出与总 Section 数、缺图数、固定 7 天保留期、精确到期时间、任务状态和百分比。排队/运行可取消，未到期的失败/取消可重试原任务，完成后按实际格式提供下载；不自动下载，不提供保存位置选择。 |

| Section 图片详情 | 当前图或候选图可打开大图，查看 current 状态、版本、来源、时间、文件元数据、生成 UUID/Provider/模型和 Premise 引用摘要；候选图可在 Dialog 中设为当前。 |

## jobs

| Job / Worker | 触发条件 | 策略 |
|---|---|---|
| `comic_storyboard_generation` | 用户为 Chapter 生成分镜 | 冻结模型、Prompt、`max_section_count` 和规划；重试不重新解析输入。 |
| `comic_export` | 用户选定格式后创建完整导出，或确认部分导出 | 在创建事务内复检、冻结有序 ready 图片和格式；ZIP 流式压缩原图，PDF 使用纯 Go 渲染 A4 页面与中文文本封面。产物写入 Export UUID 专属 `.part`，同步落盘并原子 rename，同时计算大小与 SHA-256；仅复用同格式、未到期的 canonical ready 产物且不续期。进度按真实阶段单调推进：排队 0、启动 5、准备 10、逐图片处理 10–80、同步与发布 90–95、任务完成 100。 |
| `lumi_comic_export_cleanup_v1` | 每项目 Runtime 启动时及其后每小时 | River active-state 唯一任务，每轮最多处理 1000 项；隐藏并删除已到期终态导出、对应任务图、登记 ZIP/PDF、`.part` 和受控孤儿文件。单项失败保留为 `expired` 并在下轮幂等重试。 |
| `comic_image_generation` | 生成 Section 图片 | 运行期间阻止 Chapter 快照恢复，完成后刷新漫画状态。 |

## others

实时消息统一经 `/api/v1/ws`。`comic:section_changed`、`comic:snapshot_restored`、`comic:exports_changed`、任务和 Premise 事件只携带公开 UUIDv7 与必要状态；客户端收到后失效对应 REST query，不能把事件 payload 当事实源。活动导出不执行定时 HTTP 轮询；首次 join、重新 join 和窗口重新聚焦时统一从 REST 读取任务和 Export 投影校准状态。

兼容策略：v1 Chapter 快照在详情和恢复时回退到当前 Chapter 摘要，并从旧字段恢复分镜；旧分镜任务快照缺少 `max_section_count` 时使用 6。导出请求省略 `format` 时使用 ZIP，ZIP v4 快照 JSON/hash 不因 PDF 能力改变。既有终态导出按 `COALESCE(completed_at, created_at) + 7 天` 回填到期时间，升级后可能立即进入清理。旧 `output_file_id` 到期时先逻辑删除 File 使 Asset URL 失效，再经引用复检与审计的 export-only GC 回收独占 object；共享 object 只移除对应逻辑 File。损坏 JSON 返回稳定错误，不能部分恢复。

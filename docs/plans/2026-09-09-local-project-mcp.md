# 本地项目级 MCP 实施

目标：Lumi 作为本机 MCP Server；VACS 只读参考。全部阶段实现、验证与文档完成前保持 Goal active。

1. 只读接入：核对 MCP 官方规范，提取无聊天上下文的显式外部 API 注册/校验/文档/裁剪；应用数据库独立授权；stdio 桥接与环境隔离的实例发现。
2. 编辑与生成：持久化外部调用、幂等与结果；复用 REST handler、任务运行时、模型解析及 Project Manager 租约；媒体访问与实时事件。
3. 确认及连接体验：原始操作和指纹持久化；本地 UI 确认/拒绝/过期/结果；授权管理和配置复制；桌面桥接分发。
4. 验证：真实 MCP SDK 客户端、权限/路径/裁剪/编辑/任务/确认/重启/端口/项目关闭/断开/事件/媒体；相关 Go 和前端检查。Rust 和打包仅 CI。
5. 文档：连接使用、权限、支持范围、任务确认流程、架构及 PRD。

架构约束：禁止新增路由自动暴露；禁止凭据写入项目数据库；禁止伪造 Thread/Turn/Run；桥接不接触数据库、不启动业务运行时；已受理操作独立于连接生命周期；不自动重放结果不明的普通编辑。

# 回家的星星

小狐狸捡到一颗迷路的星星。它借来灯笼，沿溪寻找最高的山坡，最终帮助星星回到夜空。


## Visual style

温暖水彩

小狐狸阿栗，橙色短毛，白色尾尖，戴蓝围巾，胆小但愿意帮助别人。

Tags: 主角, 狐狸

## 复跑与保留规则

- 可复用夹具和 stdio 记录器见 [scripts/codex-acceptance](../../../../scripts/codex-acceptance/README.md)。旧版夹具依赖过时的工具结果结构，已随历史产物归档。
- 使用隔离项目和测试素材；夹具默认把数据库、HTML、manifest 和请求日志写到系统临时目录。
- 每轮只新增或更新一份摘要，记录日期、被测版本、命令、实际结果和限制。测试计数是当次结果，不是未来固定阈值。
- 截图仅保留有长期解释价值的示例，明确普通浏览器适配器与真实宿主的区别；当前保留 6 张。
- `evidence/`、`results/`、Vite 和 Python 缓存由根 `.gitignore` 忽略。不要将过程材料重新批量加入 Git。

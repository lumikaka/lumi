# MCP 嵌入式作品工作区

独立 `/preview` 页面已移除；创作与导出后按交付范围直接进入作品总览、章节或单页。旧入口仅保留同范围的正常页面映射。

本次将四层审阅升级为复用 Web 简洁模式完整页面主体的工作区。四层导航、图片展示和历史入口兼容能力保留；旧的简化版 BookReview / StructureReview 及专属正文样式已移除，两端直接渲染共享主体。此文件同时作为功能验收清单；未验证项不表示完成。

Web 和 MCP 的章节根路由均使用 `SimplePageView`。有页面时默认选中第一页，可在章内侧栏切页；空章节由该组件显示页面管理入口。


## 功能对照与依赖

| 页面 | 共享主体 | 已有业务交互（两端应保留） | 依赖运行环境的操作 |
| --- | --- | --- | --- |
| 作品 | SimpleHomePage | 简介、规格、设定预览、章节卡片、故事/配置/章节入口 | 配置中的服务商及系统能力可在 Web 打开 |
| 章节列表 | SimpleBooksPage | 有效/回收站切换、新建、改名、排序、软删除、恢复、章节入口 | 请求 AI 助手的聊天入口需宿主适配 |
| 章节 | SimplePageView | 默认选中第一页、章内切页和逐页编辑；空章节可新建页面 | 同单页 |
| 单页 | SimplePageView | 本章侧栏、前后页、标题/类型/正文/分镜保存、脚本编辑弹窗、脚本版本采用、图片版本列表与采用、当前图片预览、参考信息、插入/排序/删除/恢复 | 导入文件、生成、导出、聊天引用 |
| 相关入口 | SimpleSettingsPage / SimpleSettingDetailPage | 设定 CRUD、历史版本、采用；候选预览 | 文件、生成、下载按宿主能力给出替代入口 |

主体及多数弹窗位于 `web/src/pages/SimpleProjectPages.jsx`，导出弹窗位于 `web/src/components/ComicExportDialog.jsx`。这些 JSX 与业务状态逻辑由 Web 和 MCP 共同使用，不再另写对应精简页面。Web 保留全局布局；MCP 仅装配页面路由、宿主工具传输和实时适配。

## 适配边界

- 导航：Web 使用浏览器路由；MCP 使用内存路由，同一资源路径在 App 内切换。只有显式 Web 入口使用 ui/open-link。
- 数据：现有 API 模块以 request 函数为注入点；共享页面通过 workspace runtime 取得服务。Web 默认 REST，MCP 经允许列表内的宿主工具转发到同一 REST handler。
- 图片：共享图片组件接受运行时图片适配；MCP 只使用公开 Asset UUID，经宿主获取有界预览，不直连文件或 localhost。
- 操作：共享表单/确认弹窗负责用户提交与 revision 冲突；权限和初始化限制仍由现有 REST/领域层执行。能力不足的文件/生成/导出操作必须显示原因和同资源 Web 入口，不自动调用模型或付费服务。
- 同步：沿用项目 WebSocket 提示及 TanStack Query 失效；首次 join、rejoin、窗口聚焦校准，通过 REST 重读事实。

## 按需读取与上下文

review_* 返回资源身份、标题、摘要、状态和 Web 入口。页面详情及历史走 UI 读取链路；UI 专用大数据放在工具结果 _meta，content/structuredContent 仅保留有界描述。App-only 可见性不作为“不进入模型上下文”的证据，需检查真实宿主传递。

作品卡片及章内导航使用摘要集合；当前页正文、分镜和版本仅在需要时读取。摘要与详情来自同一 SQLite 事实，不维护 MCP 专属事实副本。

## 验收与复跑

四层共享主体的功能清单、验证命令、实际宿主结果和限制已收敛到 [2026-11-03 验收摘要](acceptance/shared-workspace-20261103.md)。该轮使用隔离的 22 章、25 页作品；459 个前端测试、6 个相关 Go 包、4 个插件打包测试及 Web/MCP 构建通过。

真实 App 已验证标题保存和 Web 同步、版本采用与恢复、设定详情及版本读取。整本阅读实际取得全部 25 页，用户确认“封面 · 1 / 25”；单章 24 页、旧调用范围、分页、空内容、缺图、删除、失败和快速切换另有对应验证。真实普通读取和采用操作没有新增模型响应，大对象只通过 UI `_meta` 传递。

复跑方法及夹具见 [scripts/codex-acceptance](../../../scripts/codex-acceptance/README.md)。原始 wire、DOM、重复截图和临时安装状态已移出仓库；验收目录仅保留结论和少量关键截图。

## 运行环境限制

- 原生 MCP App 的 DOM/截图自动化曾超时或返回空列表。摘要区分真实宿主手动反馈、用户截图与浏览器适配器截图，不把普通浏览器结果写成原生自动化通过。
- 文件附件单次上限 6 MiB，Go 实际上传/导入已验证；原生文件选择和下载尚未完成宿主验证，保留同资源 Web 继续入口。
- AI 生成、聊天引用及项目系统配置通过 Web 继续。验收只查看导出准备并取消，没有执行生图或导出。
- 共享主体沿用 Web 浅色样式，未声称完成全应用深色适配。

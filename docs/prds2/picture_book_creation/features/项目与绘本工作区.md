# 绘本创作 — 项目与绘本工作区

> 用户先进入创作项目，再选择一本绘本继续故事与画面生产，Agent 始终在手边。

```mermaid
flowchart LR
  H[首页] -->|点击月亮邮差| P[项目主页]
  P --> S[设定]
  P -->|选择栗栗与月光灯| B[绘本工作区]
  P -->|新建绘本| N[名称与可选创作想法]
  N --> B
  B --> I[画面]
  B --> T[完整故事]
  S -->|@栗栗| A[项目 Agent 输入框]
  I -->|@第1页| A
  I -->|生成画面或新稿| G[页面画稿]
  A -->|用户主动发送| R[Agent 执行或回复]
```

项目主页只保留项目概览、共享设定和绘本列表。故事与画面属于具体绘本，用户选择绘本后进入单本工作区；全局左侧栏仍只列项目，不展开绘本树。明确不做无限画布、节点工作流和第二套全局导航。

## 1. 产品决策

| 决策 | 结论 | 原因 |
|---|---|---|
| 项目一级结构 | 项目主页、设定、绘本列表 | 项目可以包含多本绘本，项目级画面入口无法确定目标绘本。 |
| 绘本工作区 | 故事、逐页编辑、全书视图 | 故事、页面和画稿只属于当前绘本。 |
| 绘本创建 | 项目主页明确入口，Agent 可发起但提交前确认 | 资源创建必须可发现，同时避免探索性对话误建绘本。 |
| 绘本切换 | 单本工作区顶部选择器 | 保持左侧全局栏克制，不把所有绘本展开成导航树。 |
| 全局左侧栏 | 进入项目时自动收起，可随时展开 | 把横向空间让给内容与 Agent。 |
| 项目 Agent | 桌面宽屏默认展开，可收起 | `@` 设定、`@` 页面和生成画稿都是高频协作。 |
| `@` 行为 | 添加引用并聚焦输入框，不自动发送 | 避免悬浮按钮变成不可逆的隐式执行。 |
| 页面保存 | 自动保存，无常驻“保存”按钮 | 高频改文案时减少操作，但生成前必须确认保存成功。 |
| 页面生成 | 直接生成与 Agent 对话并存 | 明确结果时一步生成；需要表达意图时先 `@` 页面再对话。 |

## 3. 核心用户路径

### 3.1 进入项目继续创作

1. 用户在首页或全局左侧栏点击“月亮邮差”。
2. 右侧加载项目主页；全局左侧栏自动收起为图标栏。
3. 项目 Agent 在宽度允许时展开，并绑定“月亮邮差”上下文。
4. 用户从项目主页进入共享设定，或选择“栗栗与月光灯”进入单本工作区。

### 3.2 新建一本绘本

1. 用户在“月亮邮差”项目主页点击“新建绘本”。
2. 弹窗只收集绘本名称和创作想法；名称默认填入“未命名绘本”，创作想法可留空。
3. 创作想法为空时，用户点击“创建绘本”，系统创建空白绘本并进入故事页。
4. 创作想法不为空时，主操作显示“创建并生成故事”；系统先创建绘本，再基于该想法生成故事初稿。
5. 故事生成失败时保留已创建绘本和原始创作想法，故事页提供重试，不回滚或重复创建绘本。

### 3.3 引用设定与 Agent 对话

1. 用户进入设定页，看到栗栗、月光灯、沉睡森林的平铺卡片。
2. 鼠标悬浮或键盘聚焦栗栗封面，封面右上角出现 `@`。
3. 用户点击 `@`，Agent 面板如已收起则展开，输入框加入 `@栗栗` 并获得焦点。
4. 系统不发送消息。用户继续输入“衣服颜色再明亮一些”并主动发送。
5. Agent 使用栗栗设定的公开 `uuid` 获取最新内容，回复或执行修改。

### 3.4 修改页面后直接生成新稿

1. 用户进入画面页，默认打开逐页编辑并选中第 1 页。
2. 用户修改页面文字或画面说明；停止输入 800ms 后自动保存。
3. 当前页已有画面时，主操作显示“生成新稿”；没有画面时显示“生成画面”。
4. 用户点击主操作，系统先完成尚未结束的保存，再提交生成任务。
5. 生成期间当前使用画面继续显示；成功后新增一稿，不自动替换当前使用画面。

### 3.5 引用页面与 Agent 协作生成

1. 用户悬浮当前页画面或全书视图中的页面缩略图。
2. 点击 `@` 后，输入框加入 `@第1页` 并获得焦点。
3. 用户输入“保留构图，让栗栗的表情更安心”并发送。
4. Agent 在发送时读取该页最新页面文字、画面说明、设定引用和当前使用画面。

## 4. 功能需求

### 4.1 全局左侧栏

| ID | 功能 | 规则 |
|---|---|---|
| FR-NAV-01 | 展开与收起 | 展开宽度 224px，收起宽度 60px；收起后保留 Logo、首页、搜索、项目标识和设置图标。 |
| FR-NAV-02 | 首次状态 | 用户本次会话首次进入首页时默认展开。 |
| FR-NAV-03 | 项目自动收起 | 用户从首页或侧栏进入项目且本次会话未手动调整过侧栏时，项目加载成功后自动收起。 |
| FR-NAV-04 | 尊重手动选择 | 用户手动展开或收起后，本次会话内不再因项目内部跳转自动改变。 |
| FR-NAV-05 | 收起态可识别 | 首页、搜索、项目和设置图标均提供 tooltip；项目使用稳定封面色或首字标识。 |
| FR-NAV-06 | 项目切换 | 收起态可直接切换项目；切换后项目内容、Agent 上下文和输入草稿同时切换到目标项目。 |
| FR-NAV-07 | 草稿隔离 | Agent 未发送草稿按项目 `uuid` 保存，切换项目不能把“月亮邮差”的草稿带入“会发芽的雨伞”。 |

### 4.2 首页

| ID | 功能 | 规则 |
|---|---|---|
| FR-HOME-01 | Agent 输入 | 首屏支持多行文字、附件和发送，是首页主操作。 |
| FR-HOME-02 | 关联创作 | 默认不关联；用户可关联一个项目或该项目内的一本绘本，并可替换或清除。选择绘本时同时携带其所属项目。 |
| FR-HOME-03 | 最近项目 | 显示“新建项目”和最近 3 个项目；项目卡片显示绘本数量，点击后进入项目主页。 |
| FR-HOME-04 | 发送失败 | 保留输入、附件和关联项目，提供原位重试。 |

### 4.3 项目主页

项目主页不使用“概览 / 故事 / 页面”常驻标签。页面由三个无嵌套层级的内容区组成：

| 区域 | 必须展示 | 主操作 |
|---|---|---|
| 项目概览 | 项目代表图、名称、创作方向、绘本数量、设定数量、默认画风 | 编辑项目、更多 |
| 设定入口 | 最近更新的 3 个设定封面、名称和类型 | 进入设定 |
| 绘本列表 | 每本绘本的封面、名称、可选册序、正文页数、已有画面页数 | 继续创作、新建绘本 |

规则：

- 项目代表图独立于任何绘本封面；未设置时使用项目名称首字，不自动挪用第一本绘本封面。
- 设定预览少于 3 个时展示现有设定和“新增设定”；没有设定时只展示一个明确新增入口。
- 绘本按用户设定的册序升序排列；没有册序时按创建时间升序排在有册序绘本之后。
- 绘本封面页未生成时使用虚线封面；已生成时显示当前使用的封面画面。列表不展示每页缩略图或画稿数量。
- 点击已有页面的绘本进入上次离开的故事或画面位置；新建绘本首次进入故事页。

### 4.4 绘本创建与切换

| ID | 功能 | 规则 |
|---|---|---|
| FR-CREATE-01 | 明确入口 | “新建绘本”只出现在当前项目主页的绘本区；全局左侧栏和首页的新建入口创建项目，不直接创建绘本。 |
| FR-CREATE-02 | 最小输入 | 绘本名称为 1 至 80 个 Unicode 字符，默认值“未命名绘本”；创作想法为 0 至 2000 个 Unicode 字符。创建时不询问页数、画风、比例、封面或设定。 |
| FR-CREATE-03 | 空白创建 | 创作想法为空时创建空白绘本，成功后进入故事页，不自动生成页面或画面。 |
| FR-CREATE-04 | 带想法创建 | 创作想法不为空时按钮显示“创建并生成故事”；先创建绘本，再提交故事生成任务，不继续自动分页或出图。 |
| FR-CREATE-05 | 共享设定 | 新绘本可直接引用项目共享设定，不复制设定数据；绘本记录本册实际使用的设定引用。 |
| FR-CREATE-06 | 创建失败 | 创建请求失败时弹窗保持打开，名称和创作想法不清空，按钮恢复可用并提示“绘本创建失败，请重试”。 |
| FR-CREATE-07 | 故事生成失败 | 绘本创建成功但故事生成失败时进入该绘本故事页，保留创作想法并提供“重新生成故事”；重试不得新建第二本绘本。 |
| FR-CREATE-08 | Agent 创建 | Agent 识别到新建绘本意图后展示名称与创作想法确认卡；用户点击确认后才创建。 |
| FR-CREATE-09 | 绘本切换 | 故事页和画面页顶部显示“项目名称 / 绘本名称”及绘本选择器；切换后同步切换故事、页面、Agent 上下文和未发送草稿。 |

### 4.5 设定页

| ID | 功能 | 规则 |
|---|---|---|
| FR-SET-01 | 平铺列表 | 角色、场景、道具在同一网格平铺，按最近编辑时间倒序；首次加载 30 个，滚动到底继续加载 30 个；首期不增加二级分类导航。 |
| FR-SET-02 | 设定卡片 | 展示设定封面、名称、类型和当前版本；点击卡片主体进入设定编辑。 |
| FR-SET-03 | `@` 控件 | `@` 仅出现在设定封面右上角；鼠标悬浮、卡片键盘聚焦时显示，触屏设备常显。 |
| FR-SET-04 | 添加引用 | 点击 `@` 后展开 Agent、加入结构化引用并聚焦输入框；不发送消息。 |
| FR-SET-06 | 删除引用 | 用户可在发送前删除引用；删除只影响本条草稿，不删除设定。 |
| FR-SET-07 | 新建设定 | 顶部提供“新增设定”；创建时类型只允许角色、场景、道具。 |

### 4.6 画面页：逐页编辑

逐页编辑为默认视图，结构从左到右为页面缩略图栏、当前页编辑区、Agent 面板。

| ID | 功能 | 规则 |
|---|---|---|
| FR-IMG-01 | 页面缩略图 | 未生成使用虚线封面；已生成显示当前使用画面和页码；不附加“1稿、3稿、未生成”文字。 |
| FR-IMG-02 | 当前画面 | 页面已有画面时展示当前使用画面；右下角提供“3稿”入口，点击后打开画稿选择。 |
| FR-IMG-03 | 页面编辑 | 页面文字和画面说明可直接修改；设定引用在下方展示和增删。 |
| FR-IMG-04 | 自动保存 | 停止输入 800ms 后保存；状态仅显示“保存中、已保存、保存失败”。“已保存”2 秒后弱化。 |
| FR-IMG-05 | 直接生成 | 无画面显示“生成画面”，已有画面显示“生成新稿”；提交前等待当前自动保存完成。 |
| FR-IMG-06 | 生成互斥 | 同一页面同一时间只允许 1 个画面生成任务；按钮提交后禁用并显示“生成中”。 |
| FR-IMG-07 | 生成结果 | 第一张成功画面自动成为当前使用画面；新增画稿只进入稿件列表，不替换已有当前使用画面。 |
| FR-IMG-08 | 生成失败 | 当前使用画面和页面内容保持不变；按钮恢复可用并提示“画面生成失败，请重试”。 |
| FR-IMG-09 | 页面 `@` | 悬浮或聚焦当前画面时显示 `@`；点击后把当前页加入 Agent 输入框。 |
| FR-IMG-10 | 更多操作 | 页面删除、复制和调整顺序放入“更多”；首屏不常驻低频操作。 |

若自动保存失败，直接生成被阻止，页面保留本地编辑缓冲，并显示“页面尚未保存，重试保存后才能生成”。

### 4.7 画面页：全书视图

| ID | 功能 | 规则 |
|---|---|---|
| FR-BOOK-01 | 视图切换 | 顶部使用“逐页编辑 / 全书视图”分段控件，切换不改变当前页和 Agent 草稿。 |
| FR-BOOK-02 | 页面呈现 | 按封面、正文页、封底顺序平铺；未生成是虚线缩略图，已生成是当前使用画面加页码。 |
| FR-BOOK-03 | 进入单页 | 点击页面缩略图切换回逐页编辑并选中该页。 |
| FR-BOOK-04 | 页面 `@` | 每个页面悬浮或键盘聚焦时显示 `@`；点击只加入 Agent 输入框。 |
| FR-BOOK-05 | 批量生成 | “生成空白页画面”只处理没有可用画面的正文页，不重新生成已有画面的页面，不自动生成可选封面和封底。 |
| FR-BOOK-06 | 全屏阅读 | 全屏阅读按成书顺序使用当前画面；未生成页面显示空白页占位，不触发生成。 |

### 4.8 Agent 面板与引用

| ID | 功能 | 规则 |
|---|---|---|
| FR-AGENT-01 | 默认状态 | 视口宽度不小于 1200px 时，进入项目默认展开；小于 1200px 时默认收起，通过顶部 Agent 图标覆盖打开。 |
| FR-AGENT-02 | 分层上下文 | 项目主页和设定页显示当前项目；故事、逐页编辑和全书视图同时显示当前项目与当前绘本；逐页编辑再显示当前页。 |
| FR-AGENT-03 | 引用数据 | 引用包含对象类型、公开 `uuid` 和显示名称；禁止把数据库内部 `id` 写入前端状态或消息 payload。 |
| FR-AGENT-04 | 发送时解析 | Agent 在用户发送时读取引用对象的最新内容，不冻结点击 `@` 时的旧内容。 |
| FR-AGENT-05 | 未保存编辑 | 当前页仍在保存时发送 `@第1页`，系统先完成保存；保存失败则保留消息并阻止发送。 |
| FR-AGENT-06 | 发送成功 | 消息加入会话，清空输入和本条引用；项目上下文保持。 |
| FR-AGENT-07 | 发送失败 | 输入文字与引用完整保留，提供重试，不重复执行已成功的工具调用。 |

### 4.9 完整故事

- 从绘本卡片或单本工作区进入，顶部提供返回项目主页和切换绘本。
- 保留完整故事编辑、版本历史、页面生产摘要和“查看画面”。
- 完整故事属于当前绘本，不能被合并进聊天记录或页面文字，也不能被其他绘本隐式覆盖。

## 5. 状态与异常

### 5.1 侧栏状态

| 当前状态 | 用户进入首页 | 用户进入项目 | 用户手动切换 |
|---|---|---|---|
| 本次会话未手动调整 | 默认展开 | 项目加载成功后收起 | 记录用户选择 |
| 本次会话已手动调整 | 保持用户选择 | 保持用户选择 | 更新用户选择 |

### 5.2 绘本创建状态

| 当前状态 | 主操作 | 结果 |
|---|---|---|
| 名称有效、创作想法为空 | 创建绘本 | 创建空白绘本并进入故事页。 |
| 名称有效、创作想法不为空 | 创建并生成故事 | 创建绘本并启动一次故事生成任务。 |
| 名称为空或超过 80 字符 | 不可点击 | 原位显示名称约束，不提交请求。 |
| 创建提交中 | 创建中 | 禁用关闭以外的重复提交；关闭弹窗后二次进入仍显示任务结果。 |
| 绘本创建失败 | 重试 | 保留全部输入，重试使用同一个客户端请求 `uuid`。 |
| 绘本已创建、故事生成失败 | 重新生成故事 | 不重复创建绘本，只重试故事任务。 |

### 5.3 页面画面状态

| 页面情况 | 缩略图 | 生成按钮 | 当前使用画面 |
|---|---|---|---|
| 没有可用画面 | 虚线 + 页码 | 生成画面 | 无 |
| 首张生成中 | 仍为虚线 + 页码 | 生成中，不可点击 | 无 |
| 已有 1 稿 | 具体画面 + 页码 | 生成新稿 | 第 1 稿自动为当前使用 |
| 已有多稿 | 具体画面 + 页码 | 生成新稿 | 必须且只能有 1 稿当前使用 |
| 新稿生成中且已有画面 | 继续显示当前画面 + 页码 | 生成中，不可点击 | 不变 |

“待选、已确认、草稿、已完成”不作为页面画面流程状态。稿数只在当前页详情的画稿入口中展示。

### 5.4 `@` 控件状态

| 状态 | 表现 |
|---|---|
| 默认 | 封面不显示 `@`，可正常点击主体。 |
| Hover / Focus | `@` 出现在封面右上角，按钮点击区域不小于 32×32px。 |
| 已加入输入框 | `@` 短暂显示勾选反馈，输入框中的引用可见。 |
| 引用对象已删除 | 发送前标红该引用并阻止发送，允许移除失效引用。 |

### 5.5 输入约束

| 输入 | 约束 | 超限反馈 |
|---|---|---|
| 首页 / 项目 Agent 消息 | 1 至 8000 个 Unicode 字符；纯引用不允许发送 | 发送按钮不可用；超限后显示“最多输入 8000 个字符”。 |
| 项目名称 | 1 至 80 个 Unicode 字符 | 阻止创建或保存，并显示“项目名称为 1 至 80 个字符”。 |
| 绘本名称 | 1 至 80 个 Unicode 字符，同一项目内允许重名 | 阻止创建或保存，并显示“绘本名称为 1 至 80 个字符”。 |
| 绘本创作想法 | 0 至 2000 个 Unicode 字符 | 超限后阻止创建，并显示“创作想法最多 2000 个字符”。 |
| 页面文字 | 0 至 2000 个 Unicode 字符 | 停止自动保存，显示“页面文字最多 2000 个字符”。 |
| 画面说明 | 1 至 4000 个 Unicode 字符 | 停止自动保存和生成，显示“画面说明最多 4000 个字符”。 |
| 设定名称 | 1 至 80 个 Unicode 字符，同一项目内允许重名 | 超限后阻止提交并原位提示。 |

### 5.6 并发与幂等

| 写操作 | 规则 |
|---|---|
| 创建绘本 | 客户端生成一次性请求 `uuid`；重复提交返回同一本绘本的公开 `uuid`，故事生成失败后的重试不得重复创建绘本。 |
| 页面自动保存 | 请求携带页面公开 `uuid` 和内容修订号；修订号冲突时不覆盖远端，提示“页面已在其他窗口修改”，保留本地缓冲供用户复制。 |
| 页面画面生成 | 客户端生成一次性请求 `uuid`；重复提交返回同一任务，不重复生成或扣费。 |
| Agent 消息发送 | 每条消息使用客户端消息 `uuid`；网络重试不得产生两条相同消息或重复执行工具。 |
| 切换当前画稿 | 以服务端最后一次成功写入为准；冲突时刷新画稿列表并显示最新当前使用画面。 |

### 5.7 AI 服务降级

| 异常 | 触发条件 | 处理 |
|---|---|---|
| 单次提交失败 | 生成请求 10 秒内未确认或返回错误 | 自动重试 1 次；仍失败则恢复按钮，保留当前画面并提示手动重试。 |
| 新绘本故事生成失败 | 绘本已创建，故事任务返回失败 | 保留绘本和创作想法，进入故事页并提供“重新生成故事”，不回滚绘本。 |
| 生成任务失败 | 已创建任务返回失败结果 | 不新增画稿，不改变当前使用画面，展示“画面生成失败，请重试”。 |
| 服务不可用 | 健康检查连续 5 分钟失败 | 禁用生成按钮，展示“画面生成服务暂时不可用”；页面编辑、设定编辑和已有画面浏览保持可用。 |
| Agent 服务不可用 | 项目 Agent 连续 3 次请求失败 | 保留输入和引用，禁止自动重发，展示“Agent 暂时不可用，请稍后重试”。 |

### 5.8 权限

首期只支持项目拥有者。项目拥有者可以查看和编辑故事、设定、页面及画稿，可以调用 Agent 和生成画面。只读分享与多人协作不在本期范围内。

## 6. 响应式与可访问性

- 1200px 及以上：收起的全局侧栏 + 主内容 + 展开的 Agent 面板。
- 760px 至 1199px：Agent 默认收起，打开后覆盖主内容；全局侧栏保持可收起。
- 小于 760px：全局侧栏使用覆盖层；Agent 使用全屏面板；页面缩略图改为横向序列。
- Hover 出现的 `@` 必须同时支持键盘 focus；触屏设备常显，不能把 Hover 作为唯一入口。
- 所有图标按钮提供 `aria-label` 与 tooltip；选中、Hover 与 `aria-pressed` 组合态必须显式定义。
- 360px 宽度不得出现横向页面滚动、文本遮挡或按钮文字截断。

## 9. 验收标准

- **AC-01 项目进入**：Given 用户本次会话未手动调整侧栏，When 从首页点击“月亮邮差”，Then 项目主页加载成功后侧栏收起，Agent 在 1200px 宽度下展开。
- **AC-02 尊重手动选择**：Given 用户在项目中手动展开侧栏，When 从项目主页进入设定再进入“栗栗与月光灯”画面，Then 侧栏保持展开。
- **AC-03 项目主页减法**：Given 用户进入“月亮邮差”项目主页，Then 页面只出现项目概览、设定入口和绘本列表，不出现项目级画面入口或“概览 / 故事 / 页面”常驻标签。
- **AC-04 引用设定**：Given 用户悬浮栗栗封面，When 点击 `@`，Then Agent 展开、输入框出现 `@栗栗` 并聚焦，消息未发送。
- **AC-05 引用去重**：Given 输入框已有 `@栗栗`，When 再次点击栗栗的 `@`，Then 输入框仍只有一个 `@栗栗`。
- **AC-06 页面自动保存**：Given 用户修改第 1 页画面说明，When 停止输入 800ms，Then 显示“保存中”，保存成功后显示“已保存”。
- **AC-07 保存失败阻止生成**：Given 第 1 页自动保存失败，When 点击“生成新稿”，Then 不提交生成并提示先重试保存，编辑内容保留。
- **AC-08 生成新稿**：Given 第 1 页已有 3 稿且第 2 稿为当前使用，When 点击“生成新稿”并成功，Then 页面变为 4 稿，当前使用仍为第 2 稿。
- **AC-09 首稿自动采用**：Given 第 3 页没有画面，When 点击“生成画面”并成功，Then 第 1 稿自动成为当前使用画面，缩略图从虚线变为具体图。
- **AC-10 全书进入单页**：Given 用户在全书视图，When 点击第 2 页，Then 切换为逐页编辑并选中第 2 页，Agent 草稿不变。
- **AC-11 上下文草稿隔离**：Given “月亮邮差 / 栗栗与月光灯”Agent 输入框有未发送内容，When 切换到“月亮邮差 / 银色信封”，Then 新绘本不出现旧草稿；切回后旧草稿恢复。
- **AC-12 触屏可用**：Given 视口宽度 390px，Then 设定卡片和页面画面的 `@` 常显，界面无横向滚动。
- **AC-13 空白创建**：Given 用户在“月亮邮差”项目主页打开新建绘本弹窗且创作想法为空，When 使用默认名称“未命名绘本”点击“创建绘本”，Then 只创建一本空白绘本并进入故事页，不自动分页或出图。
- **AC-14 带想法创建**：Given 用户输入名称“栗栗第一次看星星”和 120 字创作想法，When 点击“创建并生成故事”，Then 创建一本绘本并只启动一次故事生成任务。
- **AC-15 创建失败保留输入**：Given 绘本创建请求失败，When 错误返回，Then 弹窗仍显示原名称和创作想法，并提供原位重试。
- **AC-16 Agent 创建确认**：Given 用户在项目 Agent 输入“帮我新建一本栗栗去海边的绘本”，When Agent 识别创建意图，Then 先展示确认卡，不在用户确认前创建绘本。
- **AC-17 绘本切换**：Given 用户正在编辑“栗栗与月光灯”第 1 页，When 顶部选择“银色信封”，Then 故事、页面、Agent 上下文和草稿全部切换到“银色信封”，项目共享设定保持可用。
